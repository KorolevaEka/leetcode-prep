# Порядок запуска зависимых тестов

Набор тестов описан картой `Map<String, List<String>> dependsOn`: ключ — имя задачи, значение — имена задач, которые должны выполниться **до** неё. Задача, упомянутая только в зависимостях (не ключ), — тоже задача, зависимостей у неё нет.

Напиши метод `Solution.runOrder(Map<String, List<String>> dependsOn)`, который возвращает `List<String>` — порядок запуска всех задач, где каждая идёт после своих зависимостей. Среди задач, готовых к запуску одновременно, первой идёт та, чьё имя меньше по алфавиту (обычное сравнение строк). Если порядок построить нельзя (цикл, в том числе задача зависит сама от себя), метод бросает `IllegalStateException`. Для пустой карты результат пустой.

```
runOrder({"report": ["tests"], "tests": ["build"], "lint": []})  ->  ["build", "lint", "tests", "report"]
runOrder({"b": ["a"], "c": []})                                    ->  ["a", "b", "c"]
runOrder({"a": ["b"], "b": ["a"]})                                 ->  IllegalStateException
```
