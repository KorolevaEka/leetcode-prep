# Первая запись не раньше момента

Лог отсортирован по времени: `int[] times` — отметки времени в секундах по возрастанию, могут повторяться. Нужно найти, с какой записи начинать разбор, если интересует время `target` и позже.

Напиши метод `Solution.firstAtLeast(int[] times, int target)`: индекс **первого** элемента, который `>= target`. Если таких нет (в том числе массив пуст), верни `times.length`. Решение должно работать за `O(log n)`, то есть бинарным поиском.

```
firstAtLeast([10, 20, 20, 30], 20)  ->  1
firstAtLeast([10, 20, 20, 30], 25)  ->  3
firstAtLeast([10, 20, 20, 30], 99)  ->  4
firstAtLeast([], 5)                 ->  0
```
