# Пик параллельных прогонов

Для каждого прогона известно время старта и время окончания `{start, end}` в секундах. Прогон занимает слот на полуинтервале `[start, end)`: в момент `end` он уже освободил слот, поэтому прогон, стартовавший ровно тогда, не пересекается с закончившимся.

Напиши метод `Solution.maxParallel(int[][] runs)`: сколько прогонов выполнялось одновременно в самый загруженный момент. Прогоны идут в произвольном порядке, у каждого `start < end`; для пустого массива ответ `0`.

```
maxParallel([[0, 5], [2, 6], [5, 8]])   ->  2
maxParallel([[0, 1], [1, 2], [2, 3]])   ->  1
maxParallel([])                         ->  0
```
