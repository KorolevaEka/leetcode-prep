# Нарастающее время прогона

Сборка прогоняет тесты один за другим, и для каждого известно время в миллисекундах. Чтобы построить график «сколько прошло к концу каждого теста», нужны нарастающие суммы.

Напиши метод `Solution.runningTotals(int[] durations)`, который возвращает новый массив той же длины: элемент `i` равен сумме `durations[0] + … + durations[i]`. Исходный массив менять нельзя. Для пустого массива результат — пустой массив.

```
runningTotals([300, 120, 80])  ->  [300, 420, 500]
runningTotals([])              ->  []
```
