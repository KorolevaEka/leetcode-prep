# Подсчёт статусов прогона

После прогона у каждого теста есть статус: `PASSED`, `FAILED`, `SKIPPED` и т. п. Для сводки нужно знать, сколько раз встретился каждый статус.

Напиши метод `Solution.countStatuses(List<String> statuses)`, который возвращает `Map<String, Integer>`: статус → сколько раз он встретился в списке. Статусы сравниваются точно, с учётом регистра (`"PASSED"` и `"passed"` — разные). Порядок ключей в карте не важен; для пустого списка результат — пустая карта.

```
countStatuses(["PASSED", "FAILED", "PASSED"])  ->  {PASSED=2, FAILED=1}
countStatuses([])                              ->  {}
```
