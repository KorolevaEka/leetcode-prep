# Самые падающие тесты

За неделю собрали список имён упавших тестов — один тест мог упасть много раз. Нужен рейтинг «топ-n по числу падений».

Напиши метод `Solution.topFailing(List<String> failedNames, int n)`, который возвращает `List<String>` из имён не более чем `n` самых часто падавших тестов: сначала те, что упали больше раз; при равном числе падений — по алфавиту (обычное сравнение строк). Если `n` больше числа разных тестов, возвращаются все; если `n <= 0` — пустой список.

```
topFailing(["b", "a", "b", "c", "a", "b"], 2)  ->  ["b", "a"]
topFailing(["z", "y", "x"], 2)                 ->  ["x", "y"]
topFailing(["a"], 5)                           ->  ["a"]
```
