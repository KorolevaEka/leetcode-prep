# Кэш с вытеснением

Клиент API хранит ответы в кэше ограниченного размера. Когда места нет, выбрасывается запись, к которой дольше всего не обращались.

Реализуй вложенный класс `Solution.LruCache<K, V>` (заготовка уже есть):

- `LruCache(int capacity)` — если `capacity < 1`, бросает `IllegalArgumentException`;
- `V get(K key)` — возвращает значение или `null`, если ключа нет; успешное чтение делает ключ самым свежим;
- `void put(K key, V value)` — добавляет или обновляет значение (ключ становится самым свежим); если записей стало больше `capacity`, удаляется самая давняя;
- `int size()` — сколько записей хранится сейчас.

Значения `null` не используются.

```
cache = new LruCache(2)
put("a", 1); put("b", 2); get("a")   // "a" свежее "b"
put("c", 3)                          // вытеснен "b"
get("b") -> null,  get("a") -> 1,  size() -> 2
```
