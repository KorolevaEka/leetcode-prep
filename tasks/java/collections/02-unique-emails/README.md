# Дедупликация адресов

Тестовые пользователи приходят из нескольких выгрузок, и один и тот же адрес мог попасть в список несколько раз, иногда в другом регистре.

Напиши метод `Solution.uniqueEmails(List<String> emails)`, который возвращает `List<String>` без дубликатов. Адреса считаются одинаковыми, если совпадают без учёта регистра. Из группы одинаковых остаётся самый первый адрес — ровно в том написании, в каком он встретился, — а порядок остальных сохраняется как во входном списке. Для пустого списка результат пустой.

```
uniqueEmails(["a@x.io", "b@x.io", "A@X.io", "a@x.io"])  ->  ["a@x.io", "b@x.io"]
uniqueEmails(["Zed@x.io", "amy@x.io", "zed@x.io"])      ->  ["Zed@x.io", "amy@x.io"]
```
