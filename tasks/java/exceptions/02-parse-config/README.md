# Разбор конфига с ошибками

Настройки стенда лежат в строках вида `ключ=значение`. Проверяемое исключение `Solution.ConfigException` (наследник `Exception`, конструктор принимает сообщение) уже есть в заготовке.

Напиши метод `Solution.parseConfig(List<String> lines) throws ConfigException`, который возвращает `Map<String, String>`:

- строка обрезается по краям; пустые строки и строки, начинающиеся с `#`, пропускаются;
- ключ и значение делятся по **первому** `=` и тоже обрезаются; значение может быть пустым и может содержать `=`;
- если в строке нет `=`, ключ пустой, или такой ключ уже встречался, метод бросает `ConfigException` с сообщением `"line N"`, где `N` — номер этой строки в исходном списке, считая с 1 (пустые и комментарии тоже считаются).

```
parseConfig(["host = qa.local", "# comment", "url=http://x/?a=b"])  ->  {host=qa.local, url=http://x/?a=b}
parseConfig(["a=1", "", "oops"])                                    ->  ConfigException("line 3")
```
