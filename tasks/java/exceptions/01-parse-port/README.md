# Проверка порта

Порт стенда приходит из конфига как строка. Напиши метод `Solution.parsePort(String text)`, который возвращает номер порта как `int`.

- пробелы по краям игнорируются: `" 8080 "` — это `8080`;
- допустимые порты — от `1` до `65535` включительно;
- во всех остальных случаях метод бросает `IllegalArgumentException`: `null`, пустая строка, не число (`"80a"`, `"8.5"`), число вне диапазона (`0`, `65536`, `-1`, слишком большое для `int`).

```
parsePort("8080")    ->  8080
parsePort("  443 ")  ->  443
parsePort("65536")   ->  IllegalArgumentException
parsePort(null)      ->  IllegalArgumentException
```
