# Шаги с откатом

Подготовка стенда состоит из шагов: создать пользователя, выдать права, загрузить данные. Если шаг упал, всё уже сделанное нужно откатить. Интерфейс `Solution.Step` и исключение `Solution.StepFailedException` (непроверяемое, конструктор `(String message, Throwable cause)`) уже есть в заготовке: у шага есть `String name()`, `void run() throws Exception` и `void undo() throws Exception`.

Напиши метод `Solution.runAll(List<Step> steps)`:

- шаги выполняются по порядку; если все прошли, метод просто завершается;
- когда шаг `run()` бросает исключение, у каждого **ранее успешно выполненного** шага вызывается `undo()` — в обратном порядке (последний сделанный откатывается первым). Упавший шаг не откатывается;
- если `undo()` тоже бросает исключение, откат продолжается дальше, а ошибка записывается в suppressed итогового исключения;
- после отката бросается `StepFailedException`: сообщение — `name()` упавшего шага, причина (`getCause()`) — исходное исключение.

```
шаги: A, B, C, где C падает  ->  вызваны A.run, B.run, C.run, затем B.undo, A.undo; исключение с сообщением «C»
```
