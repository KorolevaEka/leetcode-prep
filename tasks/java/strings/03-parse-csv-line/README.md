# Разбор строки CSV

Выгрузка тестовых данных приходит строками CSV. Поля разделены запятыми; поле можно обернуть в двойные кавычки — тогда запятая внутри него обычный символ, а двойная кавычка внутри записывается как два символа `""`.

Напиши метод `Solution.parseCsvLine(String line)`, который возвращает `List<String>` полей по порядку:

- кавычки, обрамляющие поле, в результат не попадают, `""` внутри кавычек превращается в `"`;
- пробелы не обрезаются: поле ` a ` остаётся с пробелами;
- пустые поля сохраняются, в том числе последнее: `"a,b,"` даёт три поля, а пустая строка (длина 0) — одно пустое поле;
- считай, что строка корректна: кавычки в поле либо обрамляют его целиком, либо отсутствуют.

```
parseCsvLine("id,name,status")              ->  ["id", "name", "status"]
parseCsvLine("7,\"Smith, John\",ok")        ->  ["7", "Smith, John", "ok"]
parseCsvLine("1,\"say \"\"hi\"\"\",,")        ->  ["1", "say \"hi\"", "", ""]
```
