# Сокращение длинного имени теста

В отчёте под имя теста отведено не больше `max` символов. Если имя длиннее, из него вырезается середина, а на её месте ставится `...` — так видны и начало, и конец имени.

Напиши метод `Solution.shortenMiddle(String s, int max)`:

- если `s.length() <= max`, возвращается сама строка без изменений;
- иначе результат имеет длину ровно `max`: начало строки, затем `...`, затем конец строки; на буквы остаётся `max - 3` символов, и если их число нечётное, лишний символ достаётся началу;
- если `max < 3`, метод бросает `IllegalArgumentException` (даже когда строка короткая).

```
shortenMiddle("checkout_with_promo_code_test", 12)  ->  "check...test"
shortenMiddle("abcdefghij", 6)                      ->  "ab...j"
shortenMiddle("login_test", 10)                     ->  "login_test"
```
