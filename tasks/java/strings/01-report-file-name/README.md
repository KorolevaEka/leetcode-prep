# Имя файла для отчёта

Автотесты сохраняют скриншоты и логи в файлы, имя файла строится из названия теста.
Названия пишут люди, поэтому в них бывают лишние пробелы и заглавные буквы.

Напиши метод `Solution.toFileName(String testName)`:

- пробелы по краям отбрасываются;
- слова (между ними может быть сколько угодно пробелов и табов) соединяются через `_`;
- всё приводится к нижнему регистру.

```
toFileName("Login with valid password")   ->  "login_with_valid_password"
toFileName("  Cart   is EMPTY ")           ->  "cart_is_empty"
toFileName("   ")                          ->  ""
```
