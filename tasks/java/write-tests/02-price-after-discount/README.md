# Цена после промокода

Метод `Solution.priceAfterDiscount(int priceCents, String code)` считает цену в центах после применения промокода:

- `"SAVE10"` — скидка 10 %, `"SAVE25"` — скидка 25 %. Скидка в центах — `priceCents · процент / 100` с отбрасыванием дробной части, цена — `priceCents` минус скидка;
- `"MINUS5"` — скидка 500 центов, но цена не опускается ниже 0;
- код сравнивается точно, с учётом регистра; неизвестный код, пустая строка и `null` — скидки нет;
- отрицательная цена — `IllegalArgumentException`. Цена не превышает 10 000 000.

Напиши тесты в стиле JUnit 5 (`@Test`, `assertEquals`, `assertThrows`), которые проходят на этой версии и ловят версии с ошибками. Код показан справа, менять его нельзя; импорты уже есть в заготовке.
