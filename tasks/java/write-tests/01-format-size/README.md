# Формат размера файла

Метод `Solution.formatSize(long bytes)` превращает размер файла в строку для отчёта (все единицы — по 1024):

- меньше 1024 байт — `"<n> B"`, например `"512 B"`;
- иначе размер делится на 1024 (KB), 1024² (MB), 1024³ (GB) — берётся самая крупная единица, для которой значение не меньше 1;
- значение пишется с одним знаком после запятой, лишние знаки **отбрасываются** (не округляются): `1536` → `"1.5 KB"`;
- для размеров от 1 GB единица остаётся GB: `2 TB` → `"2048.0 GB"`;
- отрицательный размер — `IllegalArgumentException`. Размеры не превышают `10^15`.

Напиши тесты в стиле JUnit 5 (`@Test`, `assertEquals`, `assertThrows`), которые проходят на этой версии и ловят версии с ошибками. Код показан справа, менять его нельзя; импорты уже есть в заготовке.
