# Кэш с вытеснением старого

Напиши класс `LruCache<V>` — маленький кэш для ответов API. Конструктор принимает вместимость `capacity` (≥ 1). Метод `put(key, value)` кладёт значение; если ключей стало больше вместимости, удаляется тот, к которому **дольше всего не обращались**. Метод `get(key)` возвращает значение или `undefined`, а обращение к ключу делает его «свежим». Геттер `size` — сколько ключей сейчас в кэше.

Обращением считается и `get`, и `put` (в том числе перезапись существующего ключа).

```
const cache = new LruCache<number>(2);
cache.put("a", 1);
cache.put("b", 2);
cache.get("a");        // 1  — теперь самый старый «b»
cache.put("c", 3);     // вытесняет «b»
cache.get("b");        // undefined
cache.size;            // 2
```
