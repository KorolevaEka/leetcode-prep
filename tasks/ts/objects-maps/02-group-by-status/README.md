# Группировка тестов по статусу

Отчёт о прогоне — список записей `{ name, status }`. Собери из него `Map`: ключ — статус, значение — список имён тестов с этим статусом.

Правила: ключи идут в порядке **первого появления** статуса в отчёте; имена внутри группы — в порядке появления и **без повторов** (если один тест попал в отчёт дважды с одним статусом, в группе он один раз).

```
groupByStatus([
  { name: "login", status: "passed" },
  { name: "cart",  status: "failed" },
  { name: "pay",   status: "passed" },
  { name: "login", status: "passed" },
])
->  Map { "passed" => ["login", "pay"], "failed" => ["cart"] }
```
