# Подсчёт тегов

У тестов в репозитории есть теги: `"smoke"`, `"api"`, `"Smoke "`. Теги вводят вручную, поэтому бывают лишние пробелы по краям и разный регистр.

Напиши функцию `countTags(tags)`: приведи каждый тег к нижнему регистру, обрежь пробелы по краям и верни объект «тег → сколько раз встретился». Пустые теги (после обрезки) пропускай.

```
countTags(["smoke", "API", "Smoke ", "api", "  "])  ->  { smoke: 2, api: 2 }
countTags([])                                       ->  {}
```
