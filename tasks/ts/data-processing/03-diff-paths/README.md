# Пути всех отличий в JSON

Два ответа API должны совпадать, но не совпадают — и нужно увидеть, где именно. Напиши `diffPaths(before, after)`: верни список путей до всех отличающихся мест, отсортированный обычной сортировкой строк.

Правила обхода:
- объекты сравниваются по ключам; путь — ключи через точку: `user.name`; если ключ есть только с одной стороны, отличием считается сам этот ключ;
- массивы сравниваются по индексам; путь — `items[2]`; лишний или недостающий элемент — отличие по его индексу;
- всё остальное (числа, строки, `null`, значения разных типов, например объект и массив) сравнивается через `===`; отличие записывается по пути до этого значения, а если различаются сами корни — путь `"$"`.

```
diffPaths({ user: { name: "a", roles: ["x", "y"] } }, { user: { name: "b", roles: ["x", "z", "w"] } })
->  ["user.name", "user.roles[1]", "user.roles[2]"]
diffPaths(1, 2)       ->  ["$"]
diffPaths({}, {})     ->  []
```
