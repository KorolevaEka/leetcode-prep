# Дубликаты в тестовых данных

Выгрузка тестовых пользователей собрана из нескольких файлов, и некоторые `id` повторяются. Напиши `dedupeById(users)`: оставь для каждого `id` только **первую** запись, а порядок остальных не меняй.

```
dedupeById([{ id: 2, name: "Ann" }, { id: 1, name: "Bob" }, { id: 2, name: "Ann (copy)" }])
->  [{ id: 2, name: "Ann" }, { id: 1, name: "Bob" }]
dedupeById([])  ->  []
```
