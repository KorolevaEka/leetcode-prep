# Сравнение двух ответов API

Ты проверяешь, что обновление не сломало ответ эндпоинта. Напиши `diffResponses(before, after)`: сравни поля верхнего уровня двух объектов и верни `{ added, removed, changed }` — массивы **имён полей**, каждый отсортирован по возрастанию:

- `added` — поля, которых не было в `before`, но есть в `after`;
- `removed` — поля, которые были в `before`, но пропали в `after`;
- `changed` — поля, которые есть в обоих объектах, но значения различаются.

Значения сравниваются по содержимому: вложенный объект или массив с тем же содержимым не считается изменением. Считай, что значения совместимы с JSON, а поля во вложенных объектах идут в одном и том же порядке.

```
diffResponses({ id: 1, name: "a", tags: ["x"] }, { id: 1, name: "b", tags: ["x"], extra: true })
->  { added: ["extra"], removed: [], changed: ["name"] }
```
