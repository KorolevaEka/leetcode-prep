# Первый элемент без any

Напиши обобщённую функцию `first`, которая возвращает первый элемент массива, а для пустого массива — `undefined`. Тип результата должен зависеть от типа массива: для `number[]` результат — `number | undefined`, для `string[]` — `string | undefined`.

```
first([10, 20, 30])    ->  10        (тип number | undefined)
first(["a", "b"])      ->  "a"       (тип string | undefined)
first([])              ->  undefined
```

Тесты частично проверяют типы на этапе компиляции: если вернуть `any`, компилятор сообщит, что `@ts-expect-error` ничего не подавил. Сигнатуру менять не нужно — напиши тело.
