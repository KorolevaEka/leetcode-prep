# Группировка с точными типами

Напиши `groupBy(items, keyOf)`: раскладывает элементы по группам, ключ группы берётся функцией `keyOf`. Результат — объект «ключ → массив элементов в исходном порядке». Если для ключа не нашлось ни одного элемента, поля в объекте нет.

Типы важны: если `keyOf` возвращает объединение литералов (например `"passed" | "failed"`), то обращаться к результату можно только по этим ключам, а тип значения — `T[] | undefined`. Сигнатуру менять не нужно.

```
groupBy([{ id: 1, status: "passed" }, { id: 2, status: "failed" }, { id: 3, status: "passed" }], r => r.status)
->  { passed: [{ id: 1, ... }, { id: 3, ... }], failed: [{ id: 2, ... }] }
```
