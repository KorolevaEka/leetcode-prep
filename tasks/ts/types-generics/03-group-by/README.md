# Группировка элементов

Напиши `groupBy(items, keyOf)`: раскладывает элементы по группам, ключ группы берётся функцией `keyOf`. Результат — объект «ключ → массив элементов в исходном порядке». Если `keyOf` вернула `undefined`, элемент пропускается. Если для ключа не нашлось ни одного элемента, поля в объекте нет. Ключи могут называться как свойства объекта (например, `constructor`).

Тесты проверяют ещё и типы результата: хорошая сигнатура не позволяет компилятору «обещать» лишнего. Сигнатуру менять не нужно — реши так, чтобы всё проверялось.

```
groupBy([{ id: 1, status: "passed" }, { id: 2, status: "failed" }, { id: 3, status: "passed" }], r => r.status)
->  { passed: [{ id: 1, ... }, { id: 3, ... }], failed: [{ id: 2, ... }] }
groupBy([1, 2, 3, 4], n => (n % 2 === 0 ? "even" : undefined))  ->  { even: [2, 4] }
```
