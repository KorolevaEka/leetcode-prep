# Выбор полей объекта

Напиши функцию `pick(obj, keys)`, которая возвращает **новый** объект только с указанными полями. Если какого-то поля в объекте нет (например, необязательное), в результате его тоже не должно быть — даже со значением `undefined`. Исходный объект не меняется.

Типы важны: результат — `Pick<T, K>`, а в `keys` допустимы только настоящие ключи `T`. Сигнатуру менять не нужно.

```
pick({ id: 1, name: "Ann", email: "a@x.io" }, ["id", "name"])  ->  { id: 1, name: "Ann" }
pick({ id: 1 }, [])                                            ->  {}
```
