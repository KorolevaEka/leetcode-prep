# Формат длительности прогона

Функция `formatDuration(totalSeconds)` превращает число секунд в короткую строку для отчёта: меньше минуты — `"45s"`; от минуты — `"2m 05s"` (секунды из двух цифр); от часа — `"1h 02m 05s"` (минуты и секунды из двух цифр). Часы и старшая единица ведущего нуля не имеют. Для отрицательного или нецелого числа функция бросает `RangeError`.

Напиши тесты в стиле Jest (`describe` / `test` / `expect`), которые проходят на этой версии и ловят версии с ошибками. Код показан справа, менять его нельзя; импорт уже есть в заготовке.
