# Ведро токенов

Класс `TokenBucket(capacity, refillPerSecond)` ограничивает частоту запросов. Ведро создаётся **полным**: `capacity` токенов. Метод `tryTake(nowMs, count = 1)` получает текущее время в миллисекундах: сначала ведро пополняется на `refillPerSecond` токенов за каждую прошедшую с прошлого вызова секунду (токены бывают дробными, но не больше `capacity`), затем, если токенов хватает на `count`, они списываются и метод возвращает `true`, иначе — `false` и ничего не списывается.

Напиши тесты в стиле Jest (`describe` / `test` / `expect`), которые проходят на этой версии и ловят версии с ошибками. Код показан справа, менять его нельзя; импорт уже есть в заготовке.
