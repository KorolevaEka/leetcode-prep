# Сравнение версий

Функция `compareVersions(a, b)` сравнивает версии вида `"1.10.2"` из нескольких чисел через точку. Возвращает `-1`, если `a` **меньше** `b`, `1`, если `a` больше `b`, и `0`, если версии равны. Части сравниваются как числа слева направо; недостающие части считаются нулями, поэтому `"1.2"` и `"1.2.0"` равны.

Напиши тесты в стиле Jest (`describe` / `test` / `expect`), которые проходят на этой версии и ловят версии с ошибками. Код показан справа, менять его нельзя; импорт уже есть в заготовке.
