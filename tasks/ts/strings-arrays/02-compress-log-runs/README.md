# Сжатие повторов в логе

Тест упал в цикле, и лог забит одной и той же строкой десятки раз. Напиши функцию `compressRuns(lines)`, которая схлопывает **подряд идущие** одинаковые строки: группа из `N > 1` строк превращается в `"<строка> (xN)"`, одиночная строка остаётся как есть.

Одинаковые строки, между которыми есть другая строка, — это разные группы.

```
compressRuns(["start", "retry", "retry", "retry", "done"])  ->  ["start", "retry (x3)", "done"]
compressRuns(["a", "b", "a"])                               ->  ["a", "b", "a"]
compressRuns([])                                            ->  []
```
