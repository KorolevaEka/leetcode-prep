# Сколько тестов упало

После прогона регрессии у тебя есть список статусов тестов: `"passed"`, `"failed"`, `"skipped"`.
Статусы приходят из разных систем, поэтому регистр бывает любой: `"FAILED"`, `"Failed"`.

Напиши функцию `countFailed(statuses)`, которая возвращает, сколько тестов упало.
Пропущенные (`"skipped"`) упавшими не считаются.

```
countFailed(["passed", "failed", "skipped", "FAILED"])  ->  2
countFailed(["passed", "passed"])                       ->  0
countFailed([])                                         ->  0
```

Типы важны: функция принимает `string[]` и возвращает `number`.
