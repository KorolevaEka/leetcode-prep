# Разбор CSS-селектора

Для PageObject удобно разобрать селектор на части. Напиши `parseSelector(selector)` для одного составного селектора: необязательный тег, затем в любом порядке `#id`, `.класс` (может быть несколько) и `[атрибут]` / `[атрибут=значение]`.

Верни `{ tag, id, classes, attrs }`: `tag` и `id` — строка или `null`, если их нет; `classes` — в порядке появления; `attrs` — объект «имя → значение» (у атрибута без значения — `""`). Значение атрибута может быть в одинарных или двойных кавычках — кавычки в результат не попадают, а внутри них допустимы любые символы, в том числе `.`, `#`, `]`.

Считай, что селектор записан корректно.

```
parseSelector('button#save.primary.big[data-test="ok"][disabled]')
->  { tag: "button", id: "save", classes: ["primary", "big"], attrs: { "data-test": "ok", disabled: "" } }
parseSelector('[title="a.b]c"]')  ->  { tag: null, id: null, classes: [], attrs: { title: "a.b]c" } }
```
