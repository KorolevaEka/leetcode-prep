# Разбор query-строки

Тест ходит по ссылкам и проверяет параметры. Напиши `parseQuery(query)`: превращает строку вида `"?page=2&sort=name"` в объект `{ page: "2", sort: "name" }`.

Правила: ведущий `?` необязателен; пары разделены `&`; имя и значение разделяет **первый** знак `=` (в значении он может встретиться ещё раз); параметр без `=` получает значение `""`; пустые части пропускаются; имена и значения нужно декодировать через `decodeURIComponent`; если параметр повторяется, побеждает последнее значение.

```
parseQuery("?page=2&sort=name")      ->  { page: "2", sort: "name" }
parseQuery("q=a%20b&flag&token=x=y") ->  { q: "a b", flag: "", token: "x=y" }
parseQuery("")                       ->  {}
```
