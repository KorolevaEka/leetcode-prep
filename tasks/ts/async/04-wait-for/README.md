# Ждать, пока условие выполнится

Классика автоматизации: ждать, пока элемент появится, статус сменится или файл будет готов. Напиши `waitFor(condition, options)`.

`condition` возвращает `boolean` или `Promise<boolean>`. Алгоритм: проверь условие; если оно истинно — завершись успешно. Иначе, если с начала ожидания прошло не меньше `timeoutMs`, отклонись ошибкой с текстом, содержащим `Timeout`. Иначе подожди `intervalMs` и повтори. Время берётся из `now()`, пауза — из `sleep(ms)`; по умолчанию это `Date.now` и настоящий `setTimeout`, в тестах их подменяют.

Первая проверка делается сразу, без паузы. Условие, ставшее истинным на проверке уже после таймаута, всё равно засчитывается: таймаут проверяется только после неудачной проверки. Если `condition` бросает ошибку, `waitFor` отклоняется этой же ошибкой.

```
// часы: now() = 0, sleep(ms) сдвигает время на ms
waitFor(() => false, { timeoutMs: 100, intervalMs: 50, now, sleep })
// проверки в моменты 0, 50, 100 — на третьей время вышло -> отклонён «Timeout …»
```
