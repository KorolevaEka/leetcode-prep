# Повтор нестабильного действия

Запрос к тестовому стенду иногда падает. Напиши `retry(action, attempts, delayMs, sleep?)`: вызывай `action` (функцию, возвращающую промис); при успехе верни его результат. При ошибке подожди `delayMs` миллисекунд и попробуй снова — всего не больше `attempts` вызовов. Если все попытки неудачны, отклонись с **последней** ошибкой.

Пауза делается вызовом `sleep(delayMs)`: четвёртый параметр по умолчанию ждёт по-настоящему через `setTimeout`, а в тестах его подменяют. После последней попытки не ждём — ждать уже нечего.

```
// action падает дважды и на третий раз возвращает "ok"
await retry(action, 5, 100)  ->  "ok"      (3 вызова, 2 паузы по 100 мс)
await retry(alwaysFails, 3, 100)           ->  отклонён последней ошибкой (3 вызова, 2 паузы)
```

`attempts >= 1`.
