# Загрузить всё сразу

Перед тестом нужно подготовить данные из нескольких источников. Каждый источник — функция без аргументов, возвращающая промис. Напиши `loadAll(loaders)`: запусти **все** загрузчики сразу (не ждя друг друга) и верни промис с массивом результатов **в том же порядке**, что и загрузчики, независимо от того, кто закончил первым.

Если хотя бы один загрузчик завершился ошибкой, итоговый промис отклоняется с этой ошибкой.

```
const slow = () => new Promise<string>(r => setTimeout(() => r("A"), 20));
const fast = () => Promise.resolve("B");
await loadAll([slow, fast])  ->  ["A", "B"]
await loadAll([])            ->  []
```
