# Первая сломанная сборка

Сборки пронумерованы от `1` до `total`. Если сборка №`k` сломана, то и все следующие тоже сломаны (до неё всё хорошо). Проверка сборки — функция `isBad(build)`, она дорогая: запускает полный прогон.

Напиши `firstBad(isBad, total)`: верни номер первой сломанной сборки или `-1`, если сломанных нет. Вызывай `isBad` как можно реже: тесты требуют не больше `log2(total) + 5` вызовов.

```
// сломаны сборки с 4-й и дальше
firstBad(n => n >= 4, 10)      ->  4
firstBad(n => false, 10)       ->  -1
firstBad(n => n >= 1, 5)       ->  1
```

`total >= 1`.
