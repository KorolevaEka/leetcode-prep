# Парные скобки в JSON-строке

Перед разбором ответа API хочется быстро понять, не обрезан ли он. Напиши `isBalanced(text)`: вернёт `true`, если все скобки `()`, `[]`, `{}` в строке парные и правильно вложены. Все остальные символы игнорируются.

```
isBalanced('{"ids": [1, 2, (3)]}')  ->  true
isBalanced("([)]")                  ->  false
isBalanced("(()")                   ->  false
isBalanced("")                      ->  true
```
