# Скользящее среднее времени ответа

Нагрузочный тест присылает время ответа по одному значению. Напиши класс `SlidingAverage`: конструктор принимает размер окна `size` (≥ 1), метод `add(value)` добавляет новое значение и возвращает среднее **последних `size` значений**. Пока значений меньше, чем `size`, среднее считается по тем, что есть.

```
const avg = new SlidingAverage(3);
avg.add(10);  // 10
avg.add(20);  // 15
avg.add(30);  // 20
avg.add(40);  // 30   (окно: 20, 30, 40)
```
