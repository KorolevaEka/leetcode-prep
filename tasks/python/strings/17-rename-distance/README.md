# Сколько правок до нового имени

Тест переименовали, и нужно оценить, насколько новое имя отличается от старого. Разрешены четыре правки по одному символу, каждая стоит 1: вставить символ, удалить символ, заменить символ другим, поменять местами два соседних символа. Регистр букв не важен (`A` и `a` одно и то же). Символ, который участвовал в обмене соседних, дальше не правится, то есть после обмена его нельзя ни заменить, ни удалить, ни снова обменять.

Напиши функцию `rename_cost(old, new)`, возвращающую минимальную суммарную стоимость правок, переводящих `old` в `new`. Строки могут быть пустыми и длиной до нескольких сотен символов.

## Пример

```
rename_cost("Login_Test", "login_test")  ->  0
rename_cost("ab", "ba")                  ->  1
rename_cost("ca", "abc")                 ->  3
rename_cost("smoke", "some")             ->  2
```
