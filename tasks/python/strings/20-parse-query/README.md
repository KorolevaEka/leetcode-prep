# Query-строка в словарь

Нужно разобрать query-строку вида `?a=1&b=2&b=3` в словарь. Ровно один ведущий `?`, если он есть, отбрасывается. Пары разделены `&`; пустые пары (`&&`, `&` в конце) и пары с пустым ключом пропускаются. Пара делится по первому `=`: всё после него, включая другие `=`, значение; без `=` значение пустая строка. Если ключ встретился один раз, значение строка; если несколько раз, список всех значений в порядке появления. Процентное кодирование и `+` не декодируются.

Напиши функцию `parse_query(qs)`.

## Пример

```
parse_query("?a=1&b=2&b=3")  ->  {"a": "1", "b": ["2", "3"]}
parse_query("flag&x=a=b")    ->  {"flag": "", "x": "a=b"}
parse_query("?")             ->  {}
```
