# Обрезка сообщения об ошибке

Длинный текст ошибки нужно уместить в колонку отчёта шириной `limit` символов. Если сообщение не длиннее `limit`, оно остаётся как есть. Иначе берутся первые `limit - 3` символов и к ним добавляется `"..."`, так что итог ровно `limit` символов. Если `limit` меньше 3, то для длинного сообщения возвращается строка из `limit` точек.

Напиши функцию `truncate(msg, limit)`. Считай, что `limit >= 0`.

## Пример

```
truncate("Connection refused", 10)  ->  "Connect..."
truncate("Timeout", 7)              ->  "Timeout"
truncate("Timeout", 2)              ->  ".."
```
