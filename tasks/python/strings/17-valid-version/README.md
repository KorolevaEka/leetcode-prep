# Валидная версия сборки

Версия сборки в имени артефакта должна иметь вид `[v]MAJOR.MINOR.PATCH[-suffix]`. Необязательная приставка `v` только строчная. MAJOR, MINOR и PATCH это десятичные числа из ASCII-цифр без ведущих нулей (`0` допустим, `01` нет), их ровно три. Необязательный суффикс идёт после первого `-` и состоит из одной или нескольких латинских букв, цифр и точек, другие символы (в том числе второй дефис и пробелы) недопустимы.

Напиши функцию `is_valid_version(s)`, возвращающую `True` или `False`.

## Пример

```
is_valid_version("v2.0.10")      ->  True
is_valid_version("1.2.3-rc.1")   ->  True
is_valid_version("1.02.3")       ->  False
is_valid_version("1.2.3-")       ->  False
```
