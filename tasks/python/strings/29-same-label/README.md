# Одинаковые подписи кнопок

Автотест сравнивает подпись кнопки в интерфейсе с ожидаемой, но в тексте бывают невидимые и «похожие» символы. Обе строки приводятся к одному виду, затем сравниваются. Приведение по порядку: нормализация Unicode `NFKC` (она, например, превращает полноширинные буквы и лигатуры в обычные, а `é` из двух символов в один); `casefold()` (`ß` равно `ss`); удаление невидимых символов `U+200B`, `U+200C`, `U+200D`, `U+2060`, `U+FEFF`; схлопывание любых пробельных символов (включая неразрывный пробел и табуляцию) в один пробел и обрезка пробелов по краям.

Напиши функцию `same_label(a, b)`, которая возвращает `True`, если после приведения строки равны. Строки, которые после приведения пустые, равны друг другу.

## Пример

```
same_label("Straße", "STRASSE")      ->  True
same_label("Log\u00a0in", "log in")  ->  True
same_label("a b", "ab")              ->  False
```
