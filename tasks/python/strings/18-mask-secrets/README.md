# Спрячь секреты в строке запроса

В логе запрос выглядит как `GET /x?user=bob&password=hunter2&next=1`. Для каждого ключа из списка `keys` значение после `key=` нужно заменить на `***`. Ключ ищется без учёта регистра (в тексте сохраняется как написан) и только целиком: перед ним не должно стоять буквы, цифры или `_`, поэтому `mypassword=1` не трогаем. Значение это все символы до ближайшего `&` или пробельного символа; пустое значение тоже заменяется на `***`. Всё остальное в строке остаётся без изменений.

Напиши функцию `mask_secrets(line, keys)`. Ключи непустые, могут содержать спецсимволы; пустой список ключей ничего не меняет.

## Пример

```
mask_secrets("GET /x?user=bob&Password=hunter2&next=1", ["password"])
    ->  "GET /x?user=bob&Password=***&next=1"
mask_secrets("mypassword=1", ["password"])   ->  "mypassword=1"
mask_secrets("a=1 token=xyz b=2", ["token"])
    ->  "a=1 token=*** b=2"
```
