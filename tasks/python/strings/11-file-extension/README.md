# Расширение файла артефакта

Для группировки артефактов прогона нужно знать расширение файла: часть имени после последней точки, в нижнем регистре. Имя файла это то, что стоит после последнего `/` (других разделителей нет). Точка в каталоге не считается. Если у файла нет расширения (точки нет, имя начинается с точки и других точек не содержит, как `.gitignore`, или после последней точки пусто), результат пустая строка.

Напиши функцию `file_extension(path)`.

## Пример

```
file_extension("logs/run.1/Trace.TAR.GZ")  ->  "gz"
file_extension("dir.v2/readme")            ->  ""
file_extension("cfg/.gitignore")           ->  ""
```
