# Сколько раз был ретрай

В логе прогона слово `retry` встречается в разных видах: `retry`, `Retrying`, `RETRY`. Нужно посчитать все вхождения подстроки `retry` в тексте без учёта регистра. Вхождения не пересекаются, а несколько штук в одной строке лога считаются все.

Напиши функцию `count_retries(log)`. Для пустого лога результат 0.

## Пример

```
count_retries("Retrying step 3")      ->  1
count_retries("RETRY retry")          ->  2
count_retries("step ok\nstep ok")     ->  0
```
