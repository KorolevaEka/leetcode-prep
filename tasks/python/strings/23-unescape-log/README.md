# Раскрыть экранирование в логе

Лог хранит спецсимволы в экранированном виде. Нужно раскрыть последовательности: `\n` в перевод строки, `\t` в табуляцию, `\\` в один обратный слеш, `\"` в двойную кавычку, `\xNN` в символ с кодом `NN` (ровно две шестнадцатеричные цифры, любой регистр). Если после `\x` нет двух hex-цифр, неизвестная последовательность вроде `\q`, или `\` последний символ строки, то эти символы остаются в тексте как есть. Строка обрабатывается за один проход слева направо: результат раскрытия повторно не разбирается (`\\n` даёт два символа `\` и `n`).

Напиши функцию `unescape_log(s)`.

## Пример

```
unescape_log(r"say \"hi\"")  ->  'say "hi"'
unescape_log(r"C:\\tmp")     ->  r"C:\tmp"
unescape_log(r"\x41\q\x4")   ->  r"A\q\x4"
```
