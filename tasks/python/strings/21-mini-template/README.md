# Шаблон письма с условиями

Шаблон письма содержит текст и теги. `{{ name }}` заменяется на `str(ctx[name])`, а если такого имени в `ctx` нет, на пустую строку. Блок `{% if name %}...{% endif %}` выводится, только если значение истинно (по правилам Python, отсутствующее имя ложно); `{% if not name %}` наоборот; необязательный `{% else %}` задаёт вторую ветку. Блоки могут вкладываться друг в друга. Всё вне тегов копируется как есть, включая переводы строк. Пробелы внутри тегов необязательны. Подставленные значения повторно не разбираются. Незавершённый тег (например `{% if x` без `%}`) остаётся обычным текстом.

Напиши функцию `render(tpl, ctx)`. `ValueError` нужен для `else` или `endif` без открытого `if`, второго `else` у одного `if`, `if` без `endif` в конце, а также для неизвестной команды или неверного числа слов в теге `{% ... %}`, и это касается и пропускаемых веток.

## Пример

```
render("Hi{% if vip %}, VIP{% endif %}!", {"vip": True})
    ->  "Hi, VIP!"
render("{% if a %}A{% else %}{{ n }}{% endif %}", {"n": 5})
    ->  "5"
render("{% endif %}", {})   ->  ValueError
```
