# Маска имён файлов

Автотест выбирает артефакты по маске. Маска должна совпасть со всем именем целиком (регистр значим). Символы маски: `?` один любой символ, кроме `/`; `*` любая последовательность символов (в том числе пустая), не содержащая `/`; две и более `*` подряд (`**`) любая последовательность, включая `/`; `[abc]` и `[a-c]` один символ из набора или диапазона, `[!abc]` один символ не из набора (класс никогда не совпадает с `/`, даже отрицательный). Класс закрывает первая `]`; `-` в начале или в конце набора обычный символ. `\x` означает символ `x` буквально (так можно искать `*`, `?`, `[`, `\`); внутри `[...]` обратный слеш обычный символ.

Напиши функцию `glob_match(pattern, name)`. Неправильная маска (не закрыта `[`, пустой класс `[]` или `[!]`, диапазон наоборот `[z-a]`, `\` последний в маске) даёт `ValueError` при любом `name`.

## Пример

```
glob_match("*.png", "a.png")            ->  True
glob_match("*.png", "ui/a.png")         ->  False
glob_match("logs/**/run?.txt", "logs/ui/x/run1.txt")  ->  True
glob_match("[!a-c]x", "dx")             ->  True
glob_match("[abc", "a")                 ->  ValueError
```
