# Спрячь токен в логе

Перед тем как записать токен авторизации в лог, его нужно замаскировать: все символы, кроме последних четырёх, заменить на `*`. Если в токене четыре символа или меньше, он остаётся как есть.

Напиши функцию `mask_token(token)`.

## Пример

```
mask_token("abcd1234efgh")  ->  "********efgh"
mask_token("xyz")           ->  "xyz"
mask_token("")              ->  ""
```
