# ASCII-таблица результатов

Нужно напечатать результаты прогона как текстовую таблицу. Ширина колонки это максимальная длина текста среди заголовка и всех ячеек колонки. Строка таблицы это `"| "`, ячейки через `" | "`, затем `" |"`. Каждая ячейка дополняется пробелами до ширины колонки: числа (`int` и `float`, как `str(число)`) выравниваются вправо, всё остальное и заголовки влево; `None` печатается как пустая ячейка. Вторая строка разделитель: `|`, для каждой колонки `-` в количестве ширина+2, колонки разделены `|`, в конце `|`. Строки соединяются `\n`, без перевода строки в конце.

Напиши функцию `render_table(headers, rows)`. Если строк данных нет, то результат это заголовок и разделитель. Каждая строка данных той же длины, что `headers`; значения это `str`, `int`, `float` или `None`.

## Пример

```
render_table(["test", "ms", "note"],
             [["login", 120, None], ["checkout", 95.5, "slow"]])

| test     | ms   | note |
|----------|------|------|
| login    |  120 |      |
| checkout | 95.5 | slow |
```
