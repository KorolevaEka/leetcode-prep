# Строка таблицы прогона

Консольный отчёт печатает результаты тестов в две колонки. Строка собирается так: `name`, дополненный пробелами справа до ширины `width`; затем разделитель из пробела, вертикальной черты и пробела (`" | "`); затем `status`, дополненный пробелами слева до 6 символов. Слишком длинные `name` и `status` не обрезаются.

Напиши функцию `report_row(name, status, width)`, которая возвращает готовую строку без перевода строки.

## Пример

```
report_row("login", "PASS", 8)      ->  "login    |   PASS"
report_row("checkout", "FAIL", 3)   ->  "checkout |   FAIL"
report_row("a", "SKIPPED", 1)       ->  "a | SKIPPED"
```
