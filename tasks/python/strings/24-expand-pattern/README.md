# Разворот шаблона тестовых аккаунтов

Тестовые аккаунты задают шаблоном: `user{1..3}@x.io` даёт три адреса. Группа это `{a..b}`, где `a` и `b` десятичные числа из цифр. Она заменяется всеми числами от `a` до `b` включительно. В шаблоне может быть несколько групп (достаточно поддержать до двух): результат это все сочетания, причём левая группа «старшая», то есть меняется медленнее правой. Если запись `a` начинается с нуля, числа дополняются нулями слева до длины записи `a` (`{08..10}` даёт `08`, `09`, `10`). Фигурные скобки, не подходящие под формат группы (`{x}`, `{1..}`), обычный текст. Если `a` больше `b`, нужно бросить `ValueError`.

Напиши функцию `expand_pattern(p)`. Шаблон без групп даёт список из него одного.

## Пример

```
expand_pattern("n{08..10}")    ->  ["n08", "n09", "n10"]
expand_pattern("{1..2}-{1..2}")
    ->  ["1-1", "1-2", "2-1", "2-2"]
expand_pattern("{3..1}")       ->  ValueError
```
