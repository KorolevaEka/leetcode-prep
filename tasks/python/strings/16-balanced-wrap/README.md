# Ровный перенос строк в отчёте

Текст отчёта нужно разбить на строки так, чтобы правый край был как можно ровнее. Слова берутся по пробельным символам и в строке разделены одним пробелом. Строка не длиннее `width`, кроме случая, когда в ней одно слово длиннее `width` (его не разрывают). Стоимость разбиения это сумма `(width - длина строки)²` по всем строкам, кроме последней; последняя строка бесплатна, как и строка из одного слишком длинного слова. Нужно найти разбиение с минимальной стоимостью. Если таких несколько, берётся то, у которого в первой строке больше слов, а при равенстве во второй и так далее.

Напиши функцию `balanced_wrap(text, width)`, возвращающую список строк. Для пустого текста верни `[]`. Считай, что `width >= 1`; слов может быть несколько сотен.

## Пример

```
balanced_wrap("aaa bb cc ddddd", 6)
    ->  ["aaa", "bb cc", "ddddd"]
balanced_wrap("one two", 100)   ->  ["one two"]
balanced_wrap("", 5)            ->  []
```
