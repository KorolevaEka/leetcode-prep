# Структура сьюта из отступов

Структура тестового сьюта записана текстом: каждый уровень вложенности сдвинут на два пробела. Нужно получить полный путь каждой записи (имена предков и её имя через `/`) в порядке появления в тексте. Строки разделены символом `\n`; пустые строки и строки только из пробелов пропускаются; пробелы в конце имени отбрасываются, а внутри имени остаются.

Напиши функцию `suite_paths(text)`. `ValueError` нужен, если отступ не кратен двум пробелам, в отступе есть табуляция, запись вложена глубже, чем на один уровень относительно предыдущей, или первая запись имеет отступ. Для пустого текста верни `[]`.

## Пример

```
suite_paths("smoke\n  login\n    ok\n  cart\nregression")
    ->  ["smoke", "smoke/login", "smoke/login/ok",
         "smoke/cart", "regression"]
suite_paths("a\n    b")   ->  ValueError
```
