# Лента статусов в строку

История прогонов теста записана строкой из букв: `P` проход, `F` падение и так далее. Чтобы сократить запись, подряд идущие одинаковые символы заменяются на символ и количество повторов. Счётчик пишется всегда, даже если он равен 1. Регистр различается: `P` и `p` разные символы.

Напиши функцию `compress_statuses(s)`. Для пустой строки результат пустая строка.

## Пример

```
compress_statuses("PPPFFP")  ->  "P3F2P1"
compress_statuses("Pp")      ->  "P1p1"
compress_statuses("")        ->  ""
```
