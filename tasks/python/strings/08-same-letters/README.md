# Перестановка символов в id

Два идентификатора считаются перестановкой друг друга (анаграммами), если состоят из одних и тех же символов с одинаковым количеством повторов. Регистр букв не важен, обычные пробелы игнорируются.

Напиши функцию `is_anagram(a, b)`. Две пустые строки (и строки из одних пробелов) считаются анаграммами.

## Пример

```
is_anagram("run_42", "24_NUR")   ->  True
is_anagram("ui smoke", "MOKESIU") ->  True
is_anagram("ttest", "tesst")     ->  False
```
