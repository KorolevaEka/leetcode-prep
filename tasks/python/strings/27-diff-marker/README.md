# Метка расхождения ожидаемого и фактического

В сообщении об упавшей проверке нужно показать, где именно расходятся ожидаемый и фактический текст. Сначала отбрасывается самый длинный общий префикс. Затем из оставшихся частей отбрасывается самый длинный общий суффикс, при этом суффикс не может заходить на префикс (ни в одной из строк). Результат это общий префикс, затем `[-` середина ожидаемого `+` середина фактического `]`, затем общий суффикс. Середина может быть пустой. Если строки равны, возвращается эта же строка без скобок.

Напиши функцию `diff_marker(expected, actual)`.

## Пример

```
diff_marker("hello world", "hello wide world")
    ->  "hello w[-+ide w]orld"
diff_marker("cat", "cut")   ->  "c[-a+u]t"
diff_marker("aa", "aaa")    ->  "aa[-+a]"
diff_marker("same", "same") ->  "same"
```
