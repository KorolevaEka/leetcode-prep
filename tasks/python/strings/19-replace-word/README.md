# Замена слова в тестовых данных

В тестовых данных нужно заменить слово `old` на `new`, не задевая более длинные слова. Вхождение заменяется, только если символ перед ним и символ после него не из набора `A-Z`, `a-z`, `0-9`, `_` (или это начало или конец текста). Регистр учитывается. `old` может содержать спецсимволы (`.`, `(`, `$`), они обычный текст. `new` вставляется как есть, обратные слеши в нём ничего не значат.

Напиши функцию `replace_word(text, old, new)`. Если `old` пустая строка, верни `text` без изменений.

## Пример

```
replace_word("valid_id id (id) ID", "id", "uid")
    ->  "valid_id uid (uid) ID"
replace_word("a.b axb a.bc", "a.b", "X")  ->  "X axb a.bc"
replace_word("x id", "id", "\\n")         ->  "x \\n"
```
