# Имя метода в snake_case

Названия методов из Java-кода нужно привести к `snake_case`. Заглавная латинская буква начинает новое слово (перед ней ставится `_`), если перед ней стоит строчная буква или цифра, либо если перед ней заглавная, а после неё строчная (так аббревиатура остаётся одним словом). В начале имени `_` не ставится. Затем всё переводится в нижний регистр. Уже существующие `_` и цифры остаются на своих местах.

Напиши функцию `camel_to_snake(name)`.

## Пример

```
camel_to_snake("getUserName")      ->  "get_user_name"
camel_to_snake("HTTPServerError")  ->  "http_server_error"
camel_to_snake("user2Id")          ->  "user2_id"
```
