# Общий кусок двух сообщений об ошибках

Чтобы понять, что общего у двух сообщений об ошибке, нужна их самая длинная общая непрерывная подстрока (не подпоследовательность). Если таких несколько одинаковой длины, берётся та, что начинается в строке `a` раньше всех. Если общих символов нет, результат пустая строка. Регистр значим.

Напиши функцию `longest_common_chunk(a, b)`. Строки могут быть длиной до 1500 символов, в том числе почти одинаковые и сильно повторяющиеся; решение должно укладываться во время за O(len(a) * len(b)). Модуль `difflib` в этом упражнении недоступен.

## Пример

```
longest_common_chunk("timeout at login", "timeout at checkout")
    ->  "timeout at "
longest_common_chunk("abXcd", "cdYab")   ->  "ab"
longest_common_chunk("abc", "xyz")       ->  ""
```
