# Токены фильтра отчёта

Фильтр отчёта пишут в виде `status == 'not ok' and retries>=3`. Его нужно разбить на токены. Токен это: идентификатор или число (подряд идущие ASCII-буквы, цифры, `_` и `.`); строка в одинарных кавычках целиком вместе с кавычками (пробелы внутри сохраняются, экранирования нет, строку закрывает следующая `'`); оператор из `==`, `!=`, `>=`, `<=`, `>`, `<`, `=` (двухсимвольные берутся жадно: `>=` один токен); одна скобка `(` или `)`. Пробелы, табы, `\n` и `\r` вне кавычек только разделяют токены. Любой другой символ (например одиночный `!` или `@`) и незакрытая кавычка дают `ValueError`.

Напиши функцию `tokenize_filter(expr)`, возвращающую список токенов. Для пустой строки результат `[]`.

## Пример

```
tokenize_filter("status == 'not ok' and retries>=3")
    ->  ["status", "==", "'not ok'", "and", "retries", ">=", "3"]
tokenize_filter("(a<1)")   ->  ["(", "a", "<", "1", ")"]
tokenize_filter("x == 'a")   ->  ValueError
```
