# Чистим текст ошибки

Сообщение об ошибке из консоли часто содержит лишние пробелы, табы и переводы строк. Любая последовательность из пробелов, табуляций, символов `\n` и `\r` заменяется на один обычный пробел, а такие символы по краям строки удаляются.

Напиши функцию `clean_message(text)`. Если в тексте только пробельные символы, верни пустую строку.

## Пример

```
clean_message("a\n\t b  ")           ->  "a b"
clean_message("  Error:\r\n  boom") ->  "Error: boom"
clean_message(" \t\n ")             ->  ""
```
