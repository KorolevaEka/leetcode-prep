# Перенос строк в отчёте

Длинный текст нужно разбить на строки не длиннее `width`. Слова берутся из текста по пробельным символам (любые подряд идущие пробельные символы считаются одним разделителем), в строках результата между словами ровно один пробел. Алгоритм жадный: слово добавляется в текущую строку, пока вся строка (с пробелом перед словом) остаётся не длиннее `width`, иначе начинается новая. Слово длиннее `width` не разрывается и занимает отдельную строку.

Напиши функцию `wrap_text(text, width)`, возвращающую список строк. Для пустого текста (или из одних пробелов) верни `[]`. Считай, что `width >= 1`.

## Пример

```
wrap_text("run all smoke tests now", 10)
    ->  ["run all", "smoke", "tests now"]
wrap_text("a extraordinarily b", 5)
    ->  ["a", "extraordinarily", "b"]
wrap_text("", 10)   ->  []
```
