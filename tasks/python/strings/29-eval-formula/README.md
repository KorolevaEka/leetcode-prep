# Формула ожидания

Время ожидания в тесте задаётся формулой вроде `retries*2 + (base - 1)*3`. В формуле: целые числа, имена переменных (латинские буквы, цифры, `_`, не с цифры; значения берутся из словаря), операторы `+ - * /`, унарный минус (`-x`, `2*-3`, `--3`), круглые скобки; пробелы и табуляции игнорируются. `*` и `/` выполняются раньше `+` и `-`, равные по приоритету слева направо. Деление целочисленное с округлением к нулю (`-7/2` даёт `-3`).

Напиши функцию `eval_formula(expr, variables)`, возвращающую целое число. `ValueError` нужен для пустой или неправильно записанной формулы (`1+`, `(1`, `1 2`, `()`, лишние символы), неизвестной переменной и деления на ноль. Встроенные `eval` и `ast` для решения не подходят: правила деления и ошибок у них другие.

## Пример

```
eval_formula("1+2*3", {})                    ->  7
eval_formula("retries*2 + (base-1)*3", {"retries": 3, "base": 4})  ->  15
eval_formula("-7/2", {})                     ->  -3
eval_formula("1/0", {})                      ->  ValueError
```
