# Длительность из текста

Таймаут в конфиге задан строкой вроде `1h 30m`, `2m5s` или `250ms`. Нужно вернуть общее число целых секунд. Единицы: `h` часы, `m` минуты, `s` секунды, `ms` миллисекунды (`5ms` это миллисекунды, а не `5m`). Часть состоит из неотрицательного целого числа и единицы без пробела между ними; между частями и по краям пробелы необязательны. Единицы могут идти в любом порядке, но каждая не больше одного раза. Миллисекунды дают `ms // 1000` секунд (округление вниз), остальные единицы складываются как есть.

Напиши функцию `parse_duration(s)`. `ValueError` нужен для пустой или состоящей из пробелов строки, повторной единицы, неизвестной единицы, числа без единицы, единицы без числа и любых других лишних символов.

## Пример

```
parse_duration("1h 30m")   ->  5400
parse_duration("1s500ms")  ->  1
parse_duration("5m 5m")    ->  ValueError
parse_duration("90")       ->  ValueError
```
