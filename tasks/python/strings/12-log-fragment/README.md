# Короткий фрагмент лога со всеми шагами

Чтобы приложить к багу минимум лога, нужен самый короткий фрагмент из подряд идущих строк, в котором встречается каждый ключ из `keys` хотя бы один раз. Ключ встречается в строке, если он является её подстрокой (регистр значим); одна строка может содержать несколько ключей. Если подходящих фрагментов несколько одинаковой длины, берётся тот, что начинается раньше.

Напиши функцию `shortest_fragment(lines, keys)`, возвращающую список строк фрагмента. Если фрагмента нет или `keys` пуст, верни `[]`. Ключи непустые и различны; строк может быть десятки тысяч.

## Пример

```
lines = ["start", "noise", "login ok", "noise",
         "cart ok", "login ok", "pay ok"]
shortest_fragment(lines, ["login", "cart", "pay"])
    ->  ["cart ok", "login ok", "pay ok"]
shortest_fragment(["a1", "b1"], ["c"])   ->  []
```
