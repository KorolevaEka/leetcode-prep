# Имя теста для файла

Название теста вроде `"Login: SSO, retry #2"` нужно превратить в имя файла для скриншота. Правила: всё в нижнем регистре; любая последовательность символов, которые не буквы и не цифры, превращается в один дефис `-`; дефисов в начале и в конце имени быть не должно.

Напиши функцию `slugify(title)`. Если в названии нет ни одной буквы или цифры, верни пустую строку.

## Пример

```
slugify("Login: SSO, retry #2")   ->  "login-sso-retry-2"
slugify("  Checkout   Flow  ")   ->  "checkout-flow"
slugify("!!!")                    ->  ""
```
