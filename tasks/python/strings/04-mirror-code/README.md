# Зеркальный код брони

Код бронирования считается «зеркальным», если читается одинаково слева направо и справа налево. При сравнении регистр букв не важен, а дефисы `-` игнорируются; все остальные символы, в том числе пробелы, значимы.

Напиши функцию `is_mirror_code(code)`, которая возвращает `True` или `False`. Пустая строка и строка из одного символа зеркальные.

## Пример

```
is_mirror_code("Ab-ba")  ->  True
is_mirror_code("ab a")   ->  False
is_mirror_code("A-b-c")  ->  False
```
