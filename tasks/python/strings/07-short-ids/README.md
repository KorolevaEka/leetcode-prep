# Короткие id тестов

В консоли имена тестов сокращают до самого короткого префикса, по которому имя ещё можно отличить от остальных: префикс не должен быть началом никакого другого имени из списка. Если такого префикса нет (имя само является началом другого имени), остаётся имя целиком. Регистр значим.

Напиши функцию `shortest_prefixes(names)`, возвращающую сокращения в том же порядке, что и имена. Имена непустые и все различны; в списке может быть несколько тысяч имён. Для пустого списка верни `[]`.

## Пример

```
shortest_prefixes(["login_ok", "login_fail", "logout", "cart"])
    ->  ["login_o", "login_f", "logo", "c"]
shortest_prefixes(["ab", "abc"])   ->  ["ab", "abc"]
shortest_prefixes(["x"])           ->  ["x"]
```
