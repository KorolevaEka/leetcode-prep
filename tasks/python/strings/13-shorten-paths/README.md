# Короткие пути скриншотов

В отчёте пути к скриншотам сильно повторяются. Нужно убрать у всех путей общий префикс, но только по целым компонентам (путь делится по `/`, пустой компонент у абсолютного пути считается обычным). Общий префикс ищется среди каталогов, то есть имя файла (последний компонент) всегда остаётся. Один путь сокращается до одного имени файла.

Напиши функцию `shorten_paths(paths)`, возвращающую список коротких путей в том же порядке. Для пустого списка верни `[]`. Считай, что пути непустые и не заканчиваются на `/`.

## Пример

```
shorten_paths(["a/ui/x.png", "a/ui2/y.png"])
    ->  ["ui/x.png", "ui2/y.png"]
shorten_paths(["/srv/run1/a.png"])   ->  ["a.png"]
shorten_paths(["a/x.png", "b/x.png"])
    ->  ["a/x.png", "b/x.png"]
```
