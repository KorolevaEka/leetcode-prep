# Склейка базового URL и ссылки

Краулер получил страницу `base` вида `https://host/a/b/c.html?x=1#top` и ссылку `ref` и должен собрать итоговый адрес без `urllib`. Правила: если в `ref` есть `://`, это готовый адрес, он возвращается как есть. Иначе путь берётся так: `ref` с `/` в начале это путь от корня сервера; любой другой путь считается от каталога страницы (всё в пути `base` до последнего `/` включительно); если у `ref` нет пути (пусто, `?q=2`, `#top`), путь равен пути `base`. Затем сегменты `.` убираются, а `..` убирает предыдущий сегмент (выше корня не поднимается); если путь заканчивается на `.` или `..`, в конце ставится `/`. Часть `ref` от первого `?` или `#` добавляется в конец без изменений, а query и фрагмент самого `base` не сохраняются никогда.

Напиши функцию `resolve_url(base, ref)`. Считай, что `base` абсолютный, без `.`/`..` и `//` в пути (путь может отсутствовать, тогда это `/`), а `ref` не начинается с `//`.

## Пример

```
base = "https://qa.io/app/v1/page.html?x=1"
resolve_url(base, "../img/a.png") ->  "https://qa.io/app/img/a.png"
resolve_url(base, "?q=2")  ->  "https://qa.io/app/v1/page.html?q=2"
resolve_url(base, "/login")  ->  "https://qa.io/login"
```
