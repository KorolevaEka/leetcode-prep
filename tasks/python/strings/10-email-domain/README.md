# Домен из e-mail

Для отчёта по тестовым аккаунтам нужен домен из адреса. Сначала пробелы по краям срезаются и адрес приводится к нижнему регистру. Если после этого в нём ровно одна `@` и после неё что-то есть, результат это всё, что стоит после `@`. Во всех остальных случаях (нет `@`, их больше одной, домен пустой) результат пустая строка. Локальную часть до `@` не проверяем: она может быть пустой.

Напиши функцию `email_domain(email)`.

## Пример

```
email_domain("Ann@Example.COM")    ->  "example.com"
email_domain("  bob@mail.io  ")    ->  "mail.io"
email_domain("a@b@c")              ->  ""
```
