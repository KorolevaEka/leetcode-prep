# Скобки в селекторе

Автотест собирает сложный селектор вида `div[data-id="a(1)"] > ul{...}`, и перед отправкой его нужно проверить на парность скобок. Скобки бывают трёх видов: `()`, `[]`, `{}`. Все остальные символы игнорируются. Строка корректна, если каждая закрывающая скобка закрывает ближайшую незакрытую открывающую того же вида и в конце не осталось незакрытых.

Напиши функцию `is_balanced(selector)`, которая возвращает `True` или `False`. Пустая строка корректна.

## Пример

```
is_balanced("a[b(c)]{d}")  ->  True
is_balanced("a[b(c])")     ->  False
is_balanced("a)(")         ->  False
is_balanced("((")          ->  False
```
