# Пакет JSON с номерами ошибок

Каждая непустая строка — отдельный JSON-документ. Верни (список_успешных_значений, номера_ошибочных_строк), номера начинаются с 1 и учитывают пустые строки. Ошибка одной строки не останавливает разбор остальных.

Реализуй `parse_ndjson(text)`. Входные коллекции менять нельзя.

## Пример

```python
parse_ndjson('1\n\nBAD\n{"x":2}') → ([1, {'x': 2}], [3])
```
