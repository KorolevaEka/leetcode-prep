# Поток сообщений с длиной varint

Поток содержит сообщения: длина в base-128 varint и затем указанное число сырых байтов. В varint младшие 7 бит каждого байта — данные, старший бит означает продолжение; длина не больше 2³¹−1, кодировка кратчайшая. Пустое сообщение допустимо. Обрыв, лишняя группа, некратчайшая кодировка или длина вне диапазона вызывают ValueError.

Реализуй `decode_frames(data)`. Входные коллекции менять нельзя.

## Пример

```python
decode_frames(b'\x03abc\x00\x01z') → [b'abc', b'', b'z']
```
