# Суммы без ошибок float

Каждая строка — десятичная сумма с обязательными двумя цифрами после точки и необязательным знаком -. Верни общую сумму строкой с двумя знаками; отрицательный ноль выводи как 0.00. Неверный формат вызывает ValueError, вычисляй в целых копейках.

Реализуй `sum_money(values)`. Входные коллекции менять нельзя.

## Пример

```python
sum_money(['0.10', '0.20', '-0.30']) → '0.00'
```
