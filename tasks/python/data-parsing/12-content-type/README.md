# Тип содержимого и параметры

Раздели Content-Type по точкам с запятой: первый фрагмент — тип в нижнем регистре, остальные — name=value. Имена параметров приведи к нижнему регистру и убери внешние пробелы. Значения не содержат кавычек или ;, повторный параметр заменяет предыдущий.

Реализуй `content_type(header)`. Входные коллекции менять нельзя.

## Пример

```python
content_type('Text/Plain; Charset=UTF-8') → ('text/plain', {'charset': 'UTF-8'})
```
