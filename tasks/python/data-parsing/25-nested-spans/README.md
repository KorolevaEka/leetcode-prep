# Собственное время вложенных шагов

События — тройки (id,"start" или "end",timestamp), упорядоченные по неубыванию времени. Они описывают строго вложенные вызовы; конец интервала исключён. Верни словарь суммарного собственного времени по id, исключая время дочерних вызовов. Рекурсивные одинаковые id допустимы; неверная вложенность, уменьшение времени или незакрытый вызов вызывают ValueError.

Реализуй `exclusive_times(events)`. Входные коллекции менять нельзя.

## Пример

```python
exclusive_times([('a', 'start', 0), ('b', 'start', 2), ('b', 'end', 5), ('a', 'end', 7)]) → {'a': 4, 'b': 3}
```
