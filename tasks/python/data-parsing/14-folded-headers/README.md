# Заголовки с продолжениями

Каждая строка без перевода строки либо начинает поле Name: value, либо начинается с пробела/табуляции и продолжает предыдущее значение через один пробел. Имена без учёта регистра; повторы хранятся списком. Пустые строки игнорируй; продолжение без поля вызывает ValueError.

Реализуй `folded_headers(lines)`. Входные коллекции менять нельзя.

## Пример

```python
folded_headers(['X-A: first', ' next', 'x-a: second', '\tend']) → {'x-a': ['first next', 'second end']}
```
