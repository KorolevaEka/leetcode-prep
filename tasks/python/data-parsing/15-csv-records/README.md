# Таблица CSV с заголовком

Разбери CSV с запятой и стандартными двойными кавычками. Первая строка задаёт уникальные имена столбцов; остальные строки превращаются в словари. Число полей каждой строки должно совпадать с заголовком, иначе ValueError; пустой документ даёт []. Использовать csv разрешено.

Реализуй `csv_records(text)`. Входные коллекции менять нельзя.

## Пример

```python
csv_records('id,note\n1,"a,b"\n2,"x\ny"') → [{'id': '1', 'note': 'a,b'}, {'id': '2', 'note': 'x\ny'}]
```
