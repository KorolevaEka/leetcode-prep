# Временная метка UTC

Корректная метка имеет формат YYYY-MM-DDTHH:MM:SSZ. Верни число целых секунд с 1970-01-01T00:00:00Z; результат не должен зависеть от часового пояса компьютера.

Реализуй `utc_seconds(text)`. Входные коллекции менять нельзя.

## Пример

```python
utc_seconds('1970-01-01T00:00:00Z') → 0
```
