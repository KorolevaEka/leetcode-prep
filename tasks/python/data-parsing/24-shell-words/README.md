# Аргументы команды с кавычками

Разбей команду по пробелам, табуляциям и переводам строк вне кавычек. Одинарные кавычки сохраняют всё буквально; двойные сохраняют пробелы, а обратная косая черта в них экранирует любой следующий символ. Вне кавычек обратная косая тоже экранирует следующий символ. Кавычки убираются, соседние фрагменты склеиваются, пустая пара кавычек создаёт пустой аргумент. Незакрытые кавычки и конечная косая вызывают ValueError; shlex использовать нельзя.

Реализуй `command_words(text)`. Входные коллекции менять нельзя.

## Пример

```python
command_words('run "a b" \'\' x\\ y') → ['run', 'a b', '', 'x y']
```
