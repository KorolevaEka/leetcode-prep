# Разбор строки лога

Строка лога выглядит так: `2026-11-09 12:00:01 [ERROR] checkout: timeout after 30s`. Формат: дата, время, уровень в квадратных скобках, имя источника, двоеточие с пробелом и сообщение. Сообщение может само содержать двоеточия.

Напиши функцию `parse_line(line)`, которая возвращает словарь с ключами `"time"` (дата и время целиком, `"2026-11-09 12:00:01"`), `"level"` (без скобок), `"source"` и `"message"`.

## Пример

```
parse_line("2026-11-09 12:00:01 [ERROR] checkout: timeout after 30s")
  ->  {"time": "2026-11-09 12:00:01", "level": "ERROR", "source": "checkout", "message": "timeout after 30s"}
parse_line("2026-11-09 12:00:02 [INFO] api: GET /ping: ok")["message"]  ->  "GET /ping: ok"
```
