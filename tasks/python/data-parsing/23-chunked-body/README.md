# Тело HTTP с разбиением на чанки

Байтовое тело состоит из чанков: ASCII-длина в hex, CRLF, указанное число байтов, CRLF. Последний чанк имеет нулевую длину и завершается ещё одним CRLF. Расширения и трейлеры не поддерживаются; неверное обрамление, обрыв и лишний хвост вызывают ValueError. Верни склеенные байты, не декодируя полезную нагрузку.

Реализуй `decode_chunked(data)`. Входные коллекции менять нельзя.

## Пример

```python
decode_chunked(b'3\r\nabc\r\n2\r\nde\r\n0\r\n\r\n') → b'abcde'
```
