# Адрес значения по JSON Pointer

Пустой pointer обозначает весь документ. Иначе он состоит из /-сегментов; ~1 обозначает /, ~0 обозначает ~. В словаре сегмент — ключ, в списке — неотрицательный индекс без ведущих нулей. Неверный путь или экранирование вызывает ValueError.

Реализуй `json_pointer(data, pointer)`. Входные коллекции менять нельзя.

## Пример

```python
json_pointer({'a/b': {'~x': [7]}}, '/a~1b/~0x/0') → 7
```
