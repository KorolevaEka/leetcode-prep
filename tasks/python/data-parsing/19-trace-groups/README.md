# Многострочные записи журнала

Строка, начинающаяся с "@ ", открывает запись с сообщением после префикса. Любая другая строка продолжает текущую запись через `\n`, включая пустую. Продолжение до первой записи вызывает ValueError. Верни список собранных сообщений без обрезки пробелов.

Реализуй `trace_records(lines)`. Входные коллекции менять нельзя.

## Пример

```python
trace_records(['@ fail', '  frame', '', '@ pass']) → ['fail\n  frame\n', 'pass']
```
