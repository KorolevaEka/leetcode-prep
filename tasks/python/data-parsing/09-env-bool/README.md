# Логический флаг окружения

После удаления внешних пробелов и приведения к нижнему регистру строки true, yes, 1 означают True, false, no, 0 — False. Остальные значения возвращают None; пустая строка не означает False.

Реализуй `parse_flag(text)`. Входные коллекции менять нельзя.

## Пример

```python
parse_flag(' YES ') → True
```
