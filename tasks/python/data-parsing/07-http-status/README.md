# Стартовая строка HTTP-ответа

Корректная строка ответа содержит версию HTTP, трёхзначный код и необязательную фразу причины, разделённые пробелами. Верни (код_как_int, фраза); пробелы внутри фразы сохрани, внешние убери.

Реализуй `http_status(line)`. Входные коллекции менять нельзя.

## Пример

```python
http_status('HTTP/1.1 404 Not Found') → (404, 'Not Found')
```
