# Числа в столбце отчёта

Разбери строки с целыми десятичными числами, пропуская пустые строки и строки, начинающиеся с # после удаления внешних пробелов. Допустимы знаки + и -. Остальные строки гарантированно корректны.

Реализуй `integer_lines(text)`. Входные коллекции менять нельзя.

## Пример

```python
integer_lines(' 1\n#ignore\n-2\n\n+3') → [1, -2, 3]
```
