# Выборка JSON по пути с подстановками

Путь состоит из сегментов через /: обычный сегмент выбирает ключ словаря или индекс списка, * выбирает всех непосредственных детей, ** выбирает узел и всех потомков на любой глубине. Словари обходятся в порядке вставки, списки по индексам; пути-совпадения выводятся один раз в порядке обхода документа. Верни список пар (путь_кортеж, значение). Пустая строка выбирает корень; ключи не содержат / и не равны * или **, отрицательных индексов нет.

Реализуй `select_json(document, path)`. Входные коллекции менять нельзя.

## Пример

```python
select_json({'a': {'id': 1}, 'id': 2}, '**/id') → [(('a', 'id'), 1), (('id',), 2)]
```
