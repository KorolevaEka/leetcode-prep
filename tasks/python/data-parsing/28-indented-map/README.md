# Конфигурация с вложенными отступами

Подмножество конфигурации содержит строки key: value. Пустое value открывает вложенный словарь; иначе значение — строка с обрезанными внешними пробелами. Вложенность обозначена ровно двумя пробелами на уровень; ключи непустые и уникальны внутри словаря. Пустые строки игнорируются, табуляции и скачки уровня запрещены. Нарушение вызывает ValueError.

Реализуй `parse_indented(text)`. Входные коллекции менять нельзя.

## Пример

```python
parse_indented('a:\n  x: 1\n  b:\n    y: z\nc: q') → {'a': {'x': '1', 'b': {'y': 'z'}}, 'c': 'q'}
```
