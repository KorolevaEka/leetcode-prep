# Отчёт прогона из JSON

Раннер отдаёт отчёт в виде JSON-строки: `{"results": [{"name": "login", "attempts": ["failed", "passed"]}, ...]}`. У каждого теста есть список статусов его попыток (`"passed"` или `"failed"`) по порядку.

Напиши функцию `summarize(report_json)`, которая возвращает словарь `{"failed": [...], "flaky": [...]}`:
- `failed` — имена тестов, у которых **последняя** попытка упала;
- `flaky` — имена тестов, у которых последняя попытка прошла, но среди предыдущих были падения.

Порядок имён — как в отчёте. Тест без попыток игнорируй. Если ключа `"results"` нет, оба списка пустые.

## Пример

```
{"results": [{"name": "a", "attempts": ["passed"]},
             {"name": "b", "attempts": ["failed", "passed"]},
             {"name": "c", "attempts": ["passed", "failed"]}]}
  ->  {"failed": ["c"], "flaky": ["b"]}
```
