# Типизированные настройки окружения

schema сопоставляет ключам тип int, bool или str в виде строк. Верни только присутствующие ключи схемы, преобразовав значения: int через десятичный разбор, bool только true/false без учёта регистра с внешними пробелами, str без изменений. Неверное значение вызывает ValueError.

Реализуй `typed_env(values, schema)`. Входные коллекции менять нельзя.

## Пример

```python
typed_env({'a': ' -2 ', 'b': ' FALSE ', 'c': ' x ', 'other': '7'}, {'a': 'int', 'b': 'bool', 'c': 'str'}) → {'a': -2, 'b': False, 'c': ' x '}
```
