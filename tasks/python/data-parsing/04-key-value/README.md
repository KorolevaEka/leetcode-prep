# Пара ключ и значение

В строке настроек отдели ключ от значения по первому знаку =, убери внешние пробелы у обеих частей. Пустой ключ или отсутствие = дают None; пустое значение допустимо.

Реализуй `parse_pair(line)`. Входные коллекции менять нельзя.

## Пример

```python
parse_pair(' host = a=b ') → ('host', 'a=b')
```
