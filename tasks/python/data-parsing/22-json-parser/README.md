# JSON без готового декодера

Разбери JSON с объектами, массивами, строками, true, false, null и целыми числами (дробей и экспонент нет). Поддержи стандартные экранирования и \uXXXX для символов вне диапазона суррогатов; суррогаты запрещены. Разрешены JSON-пробелы, повторные ключи объекта запрещены. Неверный документ вызывает ValueError. json, ast и eval использовать нельзя.

Реализуй `parse_json(text)`. Входные коллекции менять нельзя.

## Пример

```python
parse_json(' {"a":[1,-2,true,null],"x":"a\\n\\u0410"} ') → {'a': [1, -2, True, None], 'x': 'a\nА'}
```
