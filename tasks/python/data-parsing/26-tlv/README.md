# Вложенные двоичные записи

Каждая запись содержит однобайтовый tag, двухбайтовую длину big-endian и payload. У tag с установленным старшим битом payload — последовательность таких же записей; у остальных — сырые байты. Верни список пар (tag, payload_или_список). Обрыв заголовка или payload вызывает ValueError, пустая последовательность допустима.

Реализуй `parse_tlv(data)`. Входные коллекции менять нельзя.

## Пример

```python
parse_tlv(b'\x01\x00\x02ab\x80\x00\x04\x02\x00\x01z') → [(1, b'ab'), (128, [(2, b'z')])]
```
