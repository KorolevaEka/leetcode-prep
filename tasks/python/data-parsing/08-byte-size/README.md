# Размер артефакта в байтах

Размер записан неотрицательным целым числом и суффиксом B, KiB или MiB. Между ними возможны пробелы, регистр суффикса значим. Верни число байтов; ввод гарантированно корректен.

Реализуй `byte_size(text)`. Входные коллекции менять нельзя.

## Пример

```python
byte_size('2 KiB') → 2048
```
