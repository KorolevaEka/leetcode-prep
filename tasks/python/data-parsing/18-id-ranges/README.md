# Список номеров с диапазонами

Строка содержит неотрицательные целые номера и возрастающие включительные диапазоны a-b через запятую. Внешние пробелы элементов разрешены. Верни отсортированные уникальные номера; пустой текст даёт [], неверный элемент или убывающий диапазон — ValueError.

Реализуй `parse_id_ranges(text)`. Входные коллекции менять нельзя.

## Пример

```python
parse_id_ranges(' 1-3,2,5 ') → [1, 2, 3, 5]
```
