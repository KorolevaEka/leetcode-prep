# Строка CSV с кавычками

Выгрузка тестовых данных приходит в CSV. Поля разделены запятой, но поле может быть заключено в двойные кавычки — тогда запятые внутри него не разделяют поля, а две двойные кавычки подряд внутри кавычек означают одну кавычку. Кавычки вокруг поля в результат не попадают.

Напиши функцию `parse_row(line)`, которая возвращает список значений полей. Модуль `csv` использовать не нужно: разберись с символами сам. Пустая строка даёт `[""]`, а запятая в конце строки означает пустое последнее поле.

## Пример

```
parse_row('1,Ann,ann@test.io')           ->  ["1", "Ann", "ann@test.io"]
parse_row('2,"Smith, Bob",ok')           ->  ["2", "Smith, Bob", "ok"]
parse_row('3,"say ""hi""",x')            ->  ["3", 'say "hi"', "x"]
parse_row('a,,')                         ->  ["a", "", ""]
```
