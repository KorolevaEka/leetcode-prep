# Последовательность правок документа

Примени операции add, replace, remove к копии JSON-объекта. Путь — список строковых ключей словарей и целых индексов списков. Промежуточные элементы должны существовать; add в список вставляет перед индексом (разрешён len), add в словарь записывает ключ. replace/remove требуют существования цели; пустой путь заменяет корень через add/replace, remove корня запрещён. При ошибке ValueError, исходный документ не меняется.

Реализуй `apply_patch(document, operations)`. Входные коллекции менять нельзя.

## Пример

```python
apply_patch({'x': [1, 2]}, [{'op': 'add', 'path': ['x', 1], 'value': 9}, {'op': 'remove', 'path': ['x', 0]}]) → {'x': [9, 2]}
```
