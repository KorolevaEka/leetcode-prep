# Общее окно нескольких журналов

Каждый непустой поток отсортирован по неубыванию. Найди самый короткий закрытый диапазон (lo,hi), содержащий хотя бы одно значение каждого потока. При равной длине выбирай меньший lo. Если потоков нет или один пуст, верни None.

Реализуй `common_range(streams)`. Входные коллекции менять нельзя.

## Пример

```python
common_range([[4, 10, 15, 24, 26], [0, 9, 12, 20], [5, 18, 22, 30]]) → (20, 24)
```
