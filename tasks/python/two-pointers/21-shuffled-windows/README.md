# Окна с теми же событиями

В логе идёт последовательность событий. Нужно посчитать окна из `len(pattern)` подряд идущих событий, которые состоят из тех же событий, что и `pattern`, в любом порядке и с теми же количествами повторов. Окна могут пересекаться.

 Напиши функцию `count_shuffled_windows(log, pattern)`. Если `pattern` пуст или длиннее лога, результат `0`.

## Пример

```
count_shuffled_windows(list("abcbaca"), list("abc"))  ->  3
count_shuffled_windows(list("aabab"), list("aab"))  ->  2
count_shuffled_windows(list("abc"), list("abcd"))  ->  0
```

## Ограничения

До 60 000 событий, окно до 3 000 событий; пересчитывать каждое окно заново слишком медленно.
