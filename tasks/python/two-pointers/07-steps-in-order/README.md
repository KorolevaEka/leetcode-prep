# Шаги сценария в логе

У теста есть ожидаемые шаги по порядку, а в логе прогона записаны все события подряд, среди них и посторонние. Тест считается выполненным, если все шаги встретились в логе в нужном порядке, не обязательно подряд. Одно событие лога можно засчитать только одному шагу.

Напиши функцию `steps_in_order(steps, log)`. Пустой список шагов выполнен всегда.

## Пример

```
steps_in_order(["login", "checkout"], ["login", "search", "checkout"])  ->  True
steps_in_order(["checkout", "login"], ["login", "search", "checkout"])  ->  False
steps_in_order(["a", "a"], ["a", "b"])                                  ->  False
```
