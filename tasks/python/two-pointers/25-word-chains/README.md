# Склеенные имена тестов

Все непустые слова words имеют одну длину. Найди индексы начала подстрок text, составленных из всех words подряд в любом порядке, с учётом повторов. Ответ отсортирован, пересечения разрешены; пустой words даёт [].

Реализуй `chain_starts(text, words)`. Входные коллекции менять нельзя.

## Пример

```python
chain_starts('barfoofoobarthefoobarman', ['bar', 'foo', 'the']) → [6, 9, 12]
```
