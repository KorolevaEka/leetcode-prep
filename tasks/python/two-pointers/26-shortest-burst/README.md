# Самый короткий всплеск с отрицательными поправками

Найди минимальную длину непустого непрерывного отрезка с суммой хотя бы target. Значения могут быть отрицательными, target положителен. Если такого отрезка нет, верни -1. Не перебирай все пары границ.

Реализуй `shortest_burst(values, target)`. Входные коллекции менять нельзя.

## Пример

```python
shortest_burst([2, -1, 2], 3) → 3
```
