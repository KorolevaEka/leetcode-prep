# Самый вместительный бассейн

Вертикальные стенки разной высоты стоят вдоль линии на расстоянии 1 друг от друга. Две стенки образуют ёмкость: её ширина — расстояние между ними, высота воды — меньшая из двух высот.

 Напиши функцию `widest_pool(levels)`, которая возвращает наибольшую площадь `ширина * высота` по всем парам стенок. Если стенок меньше двух, результат `0`.

## Пример

```
widest_pool([4, 1, 7, 3, 6, 2, 5])  ->  24
widest_pool([5, 1, 1, 1, 5])  ->  20
widest_pool([9])  ->  0
```

## Ограничения

До 30 000 стенок; перебор всех пар не уложится во время.
