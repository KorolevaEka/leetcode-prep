# Сброс переключателей блоками

Операция инвертирует ровно k соседних битов: 0 становится 1 и наоборот. Найди минимальное число операций, чтобы все биты стали 1, или -1, если это невозможно. k ≥ 1; пустой список уже готов.

Реализуй `min_resets(flags, k)`. Входные коллекции менять нельзя.

## Пример

```python
min_resets([0, 1, 0], 1) → 2
```
