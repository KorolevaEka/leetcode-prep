# Общие окна простоя

Два сервиса записали окна простоя как пары `(start, end)` — полуинтервалы `[start, end)`. Внутри каждого списка окна отсортированы и не пересекаются. Нужно найти участки, когда простаивали оба сервиса.

 Напиши функцию `shared_windows(a, b, min_len)` (`min_len >= 1`): она возвращает список пар `(start, end)` — пересечений окон из `a` и `b`, длиной не меньше `min_len`, в порядке возрастания. Пересечение каждой пары окон возвращается отдельно, даже если соседние пересечения примыкают друг к другу.

## Пример

```
shared_windows([(0, 5), (8, 12)], [(3, 9), (10, 20)], 2)  ->  [(3, 5), (10, 12)]
shared_windows([(0, 5)], [(5, 9)], 1)  ->  []
shared_windows([(0, 3), (3, 5)], [(1, 4)], 1)  ->  [(1, 3), (3, 4)]
```
