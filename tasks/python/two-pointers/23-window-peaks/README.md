# Максимум в каждом окне телеметрии

Для каждого подряд идущего окна длины k верни максимальное значение, слева направо. 1 ≤ k ≤ len(values); для пустого списка допустим только k=0, ответ []. Повторы и отрицательные значения допустимы. Не пересчитывай максимум каждого окна полным обходом.

Реализуй `window_peaks(values, k)`. Входные коллекции менять нельзя.

## Пример

```python
window_peaks([1, 3, -1, -3, 5, 3, 6, 7], 3) → [3, 3, 5, 5, 6, 7]
```
