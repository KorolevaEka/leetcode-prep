# Три счётчика в сумму

В метриках за интервал лежит список целых значений (бывают отрицательные поправки). Нужно найти все тройки значений с трёх **разных позиций**, сумма которых равна `target`.

 Напиши функцию `triples_with_sum(values, target)`: она возвращает список кортежей `(a, b, c)` с `a <= b <= c`, отсортированный по возрастанию. Тройки, одинаковые по значениям, считаются одной и возвращаются один раз.

## Пример

```
triples_with_sum([-1, 0, 1, 2, -1, -4], 0)  ->  [(-1, -1, 2), (-1, 0, 1)]
triples_with_sum([1, 2, 3], 5)  ->  []
triples_with_sum([0, 0, 0, 0], 0)  ->  [(0, 0, 0)]
```

## Ограничения

До 1000 элементов; решение должно укладываться в доли секунды.
