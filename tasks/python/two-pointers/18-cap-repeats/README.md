# Не больше k повторов

В отсортированном списке id одинаковые значения идут подряд. Нужно оставить каждое значение не более чем `k` раз — первые `k` вхождений, остальные выбросить, порядок сохранить.

 Напиши функцию `cap_repeats(ids, k)`, которая возвращает новый список. При `k = 0` результат пустой.

## Пример

```
cap_repeats([1, 1, 1, 2, 2, 3], 2)  ->  [1, 1, 2, 2, 3]
cap_repeats([1, 1, 1, 2, 2, 3], 0)  ->  []
cap_repeats([7, 7, 7], 5)  ->  [7, 7, 7]
```
