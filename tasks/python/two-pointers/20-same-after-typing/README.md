# Ввод после стираний

Тест вводит текст в поле. Символ `#` — это Backspace: он стирает предыдущий символ, а если стирать нечего, ничего не делает. Остальные символы — обычные буквы и цифры.

 Напиши функцию `same_after_typing(a, b)`, которая возвращает `True`, если после всех стираний обе строки дают один и тот же текст (обе пустые тоже считаются одинаковыми).

## Пример

```
same_after_typing("ab#c", "ad#c")  ->  True
same_after_typing("#a", "a")  ->  True
same_after_typing("abc", "ab")  ->  False
```
