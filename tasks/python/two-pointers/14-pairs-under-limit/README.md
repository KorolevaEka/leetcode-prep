# Пары тестов в лимит

Есть длительности тестов (в произвольном порядке) и лимит `limit` на суммарное время двух тестов, запущенных в одном воркере. Нужно посчитать пары тестов (по позициям, `i < j`), у которых сумма длительностей **строго меньше** `limit`. Одинаковые длительности на разных позициях образуют разные пары.

 Напиши функцию `count_pairs_under(durations, limit)`.

## Пример

```
count_pairs_under([5, 1, 3, 2], 5)  ->  2
count_pairs_under([2, 2, 2, 2], 5)  ->  6
count_pairs_under([4, 4], 8)  ->  0
```

## Ограничения

До 30 000 элементов; решение должно работать заметно быстрее перебора всех пар.
