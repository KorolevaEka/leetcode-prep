# Самый длинный участок без повторов

В логе идут названия событий. Нужно найти самый длинный непрерывный участок, в котором ни одно событие не встречается дважды.

 Напиши функцию `longest_clean_run(events)`, которая возвращает длину такого участка (`0` для пустого лога).

## Пример

```
longest_clean_run(["a", "b", "a", "c", "b", "d"])  ->  4
longest_clean_run(["ok", "ok", "ok"])  ->  1
longest_clean_run([])  ->  0
```
