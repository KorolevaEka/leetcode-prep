# Слияние двух логов

Два сервиса пишут метки времени (целые числа) в свои логи, и каждый лог уже отсортирован по возрастанию. Напиши функцию `merge_logs(a, b)`, которая возвращает один отсортированный список со всеми метками из обоих логов (повторы сохраняются). Решай за один проход, без `sorted` на объединении.

## Пример

```
merge_logs([1, 4, 9], [2, 3, 10, 11])  ->  [1, 2, 3, 4, 9, 10, 11]
merge_logs([5, 5], [5])                ->  [5, 5, 5]
merge_logs([], [7])                    ->  [7]
```
