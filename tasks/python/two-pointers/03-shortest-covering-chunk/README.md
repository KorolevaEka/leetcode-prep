# Короткий кусок лога со всеми событиями

Лог — список названий событий по порядку. Нужно найти самый короткий непрерывный кусок лога, в котором встречаются все события из набора `required` (каждое хотя бы по разу; лишние события в куске допустимы).

Напиши функцию `shortest_chunk(log, required)`, которая возвращает длину такого куска, а если подходящего куска нет — `-1`. Для пустого `required` ответ `0`.

## Пример

```
shortest_chunk(["login", "click", "error", "click", "login", "error"], {"login", "error"})  ->  2
shortest_chunk(["a", "b", "a", "c"], {"a", "b", "c"})                                          ->  3
shortest_chunk(["a", "a"], {"a", "b"})                                                         ->  -1
```
