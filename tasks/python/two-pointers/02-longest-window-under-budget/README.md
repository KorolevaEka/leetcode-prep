# Самое длинное окно в бюджет

Во время нагрузочного прогона у каждого запроса есть время ответа в миллисекундах (неотрицательное целое). Нужно найти самый длинный непрерывный участок подряд идущих запросов, суммарное время которых не больше `budget`.

Напиши функцию `longest_window(times, budget)`, которая возвращает длину такого участка (`0`, если ни один запрос не помещается).

## Пример

```
longest_window([3, 1, 2, 7, 4, 2, 1], 8)  ->  3    # лучший участок [4, 2, 1], сумма 7
longest_window([1, 1, 1], 3)              ->  3
longest_window([9, 9], 5)                 ->  0
```
