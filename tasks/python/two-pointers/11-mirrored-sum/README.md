# Парные замеры

Датчик записывает значения симметрично: первое и последнее замеры, второе и предпоследнее и так далее должны давать одну и ту же сумму `total`. Если замеров нечётное количество, средний замер образует пару сам с собой, то есть его удвоенное значение тоже должно равняться `total`.

Напиши функцию `mirrored_sum(values, total)`, которая проверяет, что все такие пары подходят. Пустой список подходит.

## Пример

```
mirrored_sum([3, 4, 5, 6, 7], 10)  ->  True      # 3+7, 4+6, 5+5
mirrored_sum([3, 4, 5, 6, 8], 10)  ->  False     # 3+8 = 11
mirrored_sum([4], 10)              ->  False     # 4+4 = 8
```
