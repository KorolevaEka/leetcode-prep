# Медиана движущегося окна

Верни медиану каждого подряд идущего окна длины k. Для чётного размера медиана — среднее двух центральных чисел. При пустом values допустим k=0, ответ []. Для непустого списка 1 ≤ k ≤ len(values); не сортируй каждое окно заново.

Реализуй `rolling_medians(values, k)`. Входные коллекции менять нельзя.

## Пример

```python
rolling_medians([1, 3, -1, -3, 5, 3, 6, 7], 3) → [1, -1, -1, 3, 5, 6]
```

## Ограничения

Число замеров — до 50 000, размер окна — до 10 001; решение должно обновлять статистику без новой сортировки каждого окна.
