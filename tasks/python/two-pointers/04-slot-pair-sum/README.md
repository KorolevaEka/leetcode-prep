# Два теста в один слот

В CI есть слот на `slot` секунд, и в него нужно уложить ровно два теста так, чтобы их длительности в сумме дали `slot` точно, без остатка. Длительности (неотрицательные целые) переданы по возрастанию. Напиши функцию `fits_pair(durations, slot)`: есть ли в списке два разных теста (две разные позиции), подходящих под слот. Один и тот же тест дважды взять нельзя.

## Пример

```
fits_pair([1, 3, 5, 8], 8)  ->  True     # 3 + 5
fits_pair([4], 8)           ->  False    # одного теста мало
fits_pair([4, 4], 8)        ->  True
```
