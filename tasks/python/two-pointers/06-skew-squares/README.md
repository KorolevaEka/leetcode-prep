# Квадраты перекосов часов

Для каждого узла измерили, на сколько миллисекунд его часы уходят от эталона: отклонение может быть отрицательным, нулевым или положительным. Список отклонений отсортирован по возрастанию. Нужно получить квадраты отклонений, тоже по возрастанию.

Напиши функцию `skew_squares(deltas)`, которая возвращает новый отсортированный список квадратов. Решай за один проход, не сортируя результат заново.

## Пример

```
skew_squares([-4, -1, 0, 3, 10])  ->  [0, 1, 9, 16, 100]
skew_squares([-3, -3, 3])         ->  [9, 9, 9]
skew_squares([])                  ->  []
```
