# Одинаковый статус после замен

В последовательности статусов разрешено заменить не больше k элементов на любые другие статусы. Найди наибольшую длину непрерывного участка, который можно сделать полностью одинаковым. k ≥ 0; пустой список даёт 0.

Реализуй `longest_uniform(statuses, k)`. Входные коллекции менять нельзя.

## Пример

```python
longest_uniform(['A', 'A', 'B', 'A', 'B', 'B', 'A'], 1) → 4
```
