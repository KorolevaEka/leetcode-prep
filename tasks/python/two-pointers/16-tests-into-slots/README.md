# Тесты по слотам

В расписании есть слоты с длинами в минутах, и есть тесты с длительностями. В один слот помещается не больше одного теста, и только если его длительность не больше длины слота; каждый тест можно поставить в один слот.

 Напиши функцию `tests_that_fit(durations, slots)`, которая возвращает максимальное число тестов, которые удастся разместить.

## Пример

```
tests_that_fit([4, 2, 7], [3, 5, 8])  ->  3
tests_that_fit([3, 1], [3])  ->  1
tests_that_fit([6, 7], [5])  ->  0
```
