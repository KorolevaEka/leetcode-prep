# Короткий фрагмент с порядком шагов

Найди кратчайший непрерывный фрагмент log, в котором steps встречаются как подпоследовательность: порядок важен, соседство не обязательно. При ничьей бери самый ранний фрагмент. Если steps пуст или полного совпадения нет, верни [].

Реализуй `shortest_replay(log, steps)`. Входные коллекции менять нельзя.

## Пример

```python
shortest_replay(['a', 'b', 'c', 'd', 'e', 'b', 'd', 'd', 'e'], ['b', 'd', 'e']) → ['b', 'c', 'd', 'e']
```
