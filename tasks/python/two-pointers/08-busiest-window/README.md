# Самая нагруженная минута

Нагрузочный прогон записал число запросов за каждую секунду (неотрицательные целые). Нужно найти окно из `k` подряд идущих секунд с наибольшим суммарным числом запросов и вернуть эту сумму.

Напиши функцию `busiest_window(rps, k)` (`k >= 1`). Если секунд меньше, чем `k`, ответ `0`. Записей может быть сотни тысяч, а окно большим, поэтому сумму каждого окна заново считать не стоит: решение должно работать за O(n).

## Пример

```
busiest_window([5, 1, 3, 7, 2], 2)  ->  10     # 3 + 7
busiest_window([4], 1)              ->  4
busiest_window([1, 2], 3)           ->  0
```
