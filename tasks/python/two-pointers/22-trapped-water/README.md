# Запас воды между датчиками

Неотрицательные высоты образуют профиль с единичной шириной столбика. Посчитай объём воды после дождя, удерживаемой между столбиками. За крайними столбиками вода не удерживается; пустой профиль даёт 0.

Реализуй `trapped_water(bars)`. Входные коллекции менять нельзя.

## Пример

```python
trapped_water([0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1]) → 6
```
