# Развернуть до маркера

В списке шагов нужно развернуть порядок начала сценария: от первого элемента до первого вхождения маркера `stop` включительно. Всё, что стоит после этого вхождения, остаётся как есть. Если маркера в списке нет, список остаётся без изменений.

Напиши функцию `reverse_upto(items, stop)`, которая возвращает новый список; исходный менять нельзя.

## Пример

```
reverse_upto([1, 2, 3, 4], 3)     ->  [3, 2, 1, 4]
reverse_upto([2, 1, 3, 1, 4], 1)  ->  [1, 2, 3, 1, 4]    # берётся первое вхождение
reverse_upto([1, 2, 3], 9)        ->  [1, 2, 3]
```
