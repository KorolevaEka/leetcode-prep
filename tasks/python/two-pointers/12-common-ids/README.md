# Общие id в двух выгрузках

Две выгрузки из разных систем содержат id пользователей по возрастанию; в каждой id может повторяться. Нужно найти id, которые есть в обеих выгрузках.

Напиши функцию `common_ids(a, b)`, которая возвращает отсортированный список таких id, каждый по одному разу. Решай за один проход по обоим спискам, без `set` и без вложенных циклов.

## Пример

```
common_ids([1, 2, 2, 3, 5], [2, 2, 4, 5])  ->  [2, 5]
common_ids([1, 1, 1], [1])                 ->  [1]
common_ids([1, 2], [3, 4])                 ->  []
```
