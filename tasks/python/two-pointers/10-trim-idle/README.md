# Простой по краям

Сервис выдаёт нагрузку по секундам, а в начале и в конце записи часто тянется простой: нулевые замеры, пока тест ещё не начался или уже закончился. Нули в середине важны, они показывают реальные паузы.

Напиши функцию `trim_idle(samples)`, которая возвращает новый список без нулей в начале и в конце. Нули в середине остаются. Если все замеры нулевые или список пуст, результат пустой список.

## Пример

```
trim_idle([0, 0, 5, 0, 3, 0])  ->  [5, 0, 3]
trim_idle([0, 0])              ->  []
trim_idle([1, 0, 0, 2])        ->  [1, 0, 0, 2]
```
