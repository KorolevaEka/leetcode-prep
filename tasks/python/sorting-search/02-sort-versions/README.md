# Сортировка версий

В списке — версии приложения вида `"1.10.2"` (числа через точки, ровно три части). Версии нужно упорядочить по возрастанию как версии, а не как строки: `"1.10.0"` новее, чем `"1.2.0"`.

Напиши функцию `sort_versions(versions)`, которая возвращает новый отсортированный список. Одинаковые версии сохраняются.

## Пример

```
sort_versions(["1.10.0", "1.2.0", "1.2.10", "1.2.9"])  ->  ["1.2.0", "1.2.9", "1.2.10", "1.10.0"]
sort_versions(["2.0.0", "10.0.0"])                     ->  ["2.0.0", "10.0.0"]
sort_versions([])                                      ->  []
```
