# События в окне времени

Метки времени событий (целые секунды) лежат в списке, уже упорядоченном по возрастанию; повторы возможны. Нужно быстро узнать, сколько событий попало в окно от `start` до `end` включительно. Список большой, а вопросов много, поэтому просматривать его целиком на каждый вопрос нельзя: на пробу ответ должен находиться за считанные обращения к элементам.

Напиши функцию `count_between(timestamps, start, end)`. Если `start > end`, ответ 0.

## Пример

```
count_between([1, 3, 3, 5, 8], 3, 5)  ->  3
count_between([1, 3, 3, 5, 8], 4, 4)  ->  0
count_between([1, 3, 3, 5, 8], 9, 2)  ->  0
```
