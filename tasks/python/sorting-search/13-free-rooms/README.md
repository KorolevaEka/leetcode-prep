# Сколько нужно стендов

Каждый интервал (start, end) задаёт занятость стенда [start, end), start < end. Найди минимальное число стендов для размещения всех прогонов. В момент окончания стенд уже доступен другому прогону.

Реализуй `room_count(intervals)`. Входные коллекции менять нельзя.

## Пример

```python
room_count([(0, 5), (2, 7), (5, 8)]) → 2
```
