# Вторая по медленности длительность

Для отчёта нужна вторая по величине длительность теста, но повторы считаются одним значением: в `[9, 9, 4]` самая большая — 9, вторая — 4. Если различных значений меньше двух, верни `None`.

Напиши функцию `second_slowest(durations)`. Исходный список менять нельзя.

## Пример

```
second_slowest([3, 9, 4, 9])  ->  4
second_slowest([5, 5, 5])     ->  None
second_slowest([2])           ->  None
second_slowest([])            ->  None
```
