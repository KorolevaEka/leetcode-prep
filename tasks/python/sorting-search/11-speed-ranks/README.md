# Места в рейтинге скорости

Тесты ранжируют по длительности: самый быстрый занимает место 1. Одинаковые длительности делят место, а следующее место пропускается: длительности `[5, 7, 7, 9]` получают места `1, 2, 2, 4`.

Напиши функцию `speed_ranks(durations)`: для каждого элемента входа (в том же порядке) верни его место.

## Пример

```
speed_ranks([7, 5, 9, 7])  ->  [2, 1, 4, 2]
speed_ranks([3, 3, 3])     ->  [1, 1, 1]
speed_ranks([])            ->  []
```
