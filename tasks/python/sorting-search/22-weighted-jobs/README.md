# Самые выгодные непересекающиеся прогоны

Задача (start, end, reward) занимает [start,end) и приносит неотрицательную награду. Выбери совместимые задачи с максимальной суммой наград; start < end, задачи могут касаться. Пустой набор даёт 0.

Реализуй `best_reward(jobs)`. Входные коллекции менять нельзя.

## Пример

```python
best_reward([(1, 3, 5), (2, 4, 6), (3, 5, 5)]) → 10
```
