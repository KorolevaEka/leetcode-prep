# Часто падающие тесты первыми

Для каждого теста известно число падений за неделю. Нужно показать список тестов от самых падающих к менее падающим. Если у тестов одинаковое число падений, они остаются в том порядке, в каком были во входном списке.

Напиши функцию `most_failing(tests)`: на входе список пар `(имя, число падений)`, на выходе список имён в нужном порядке.

## Пример

```
most_failing([("login", 2), ("cart", 5), ("search", 2), ("pay", 0)])  ->  ["cart", "login", "search", "pay"]
most_failing([("a", 1), ("b", 1), ("c", 1)])                           ->  ["a", "b", "c"]
```
