# Где сломался порядок лога

Записи лога должны идти по неубыванию меток времени (одинаковые метки подряд допустимы). Нужно найти первую запись, нарушающую порядок: ту, у которой метка меньше, чем у записи прямо перед ней.

Напиши функцию `first_disorder(timestamps)`: индекс такой записи или `-1`, если лог упорядочен.

## Пример

```
first_disorder([1, 2, 2, 5, 4, 9, 3])  ->  4
first_disorder([1, 2, 2, 3])           ->  -1
first_disorder([5])                    ->  -1
```
