# Контур занятости оборудования

Каждый элемент (left,right,height) задаёт прямоугольник [left,right), height > 0. Верни точки (x,h), в которых меняется максимальная высота всех активных прямоугольников. При одинаковом x должна быть одна итоговая точка; соседние равные высоты пропускаются, в конце высота становится 0.

Реализуй `skyline(buildings)`. Входные коллекции менять нельзя.

## Пример

```python
skyline([(1, 4, 3), (2, 6, 5), (6, 7, 2)]) → [(1, 3), (2, 5), (6, 2), (7, 0)]
```
