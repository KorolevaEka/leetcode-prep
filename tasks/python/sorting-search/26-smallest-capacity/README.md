# Минимальная вместимость доставки

Посылки с положительными весами отправляют в исходном порядке, не разделяя одну посылку. За день можно взять следующий непрерывный кусок с общей массой не выше вместимости. Найди минимальную целую вместимость для отправки не более чем за days дней; days ≥ 1, пустой список даёт 0.

Реализуй `shipping_capacity(weights, days)`. Входные коллекции менять нельзя.

## Пример

```python
shipping_capacity([1, 2, 3, 1, 1], 4) → 3
```
