# Ближайший допустимый таймаут

Конфиг разрешает только некоторые значения таймаута. Нужно подобрать из разрешённых то, которое ближе всего к желаемому. Если два значения одинаково близки, выбери меньшее.

Напиши функцию `closest_timeout(allowed, wanted)`. Список `allowed` не пустой и не упорядочен, повторы возможны.

## Пример

```
closest_timeout([30, 5, 10, 60], 12)  ->  10
closest_timeout([20, 10], 15)         ->  10     # 10 и 20 одинаково далеко
closest_timeout([5, 10], 100)         ->  10
```
