# Стоимость билетов на стенд

В указанные целые дни нужен доступ к стенду. Билеты действуют 1, 7 и 30 последовательных дней начиная с покупки; их цены заданы списком costs длины 3. Дни не обязательно отсортированы и могут повторяться; найди минимальную общую цену.

Реализуй `ticket_cost(days, costs)`. Входные коллекции менять нельзя.

## Пример

```python
ticket_cost([1, 4, 6, 7, 8, 20], [2, 7, 15]) → 11
```
