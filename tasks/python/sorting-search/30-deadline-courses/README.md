# Максимум курсов до дедлайнов

Курс (duration,deadline) занимает duration дней подряд; duration и deadline положительные. Учиться можно одному курсу за раз, начиная с дня 0; завершить курс разрешено ровно в deadline. Выбери порядок и подмножество с максимальным количеством курсов.

Реализуй `max_courses(courses)`. Входные коллекции менять нельзя.

## Пример

```python
max_courses([(100, 200), (200, 1300), (1000, 1250), (2000, 3200)]) → 3
```
