# Сортировка по приоритету команд

Целые значения из списка priority уникальны. Сначала выведи все элементы items, перечисленные в priority, в указанном порядке. Остальные значения отсортируй по возрастанию; повторы не теряются.

Реализуй `priority_order(items, priority)`. Входные коллекции менять нельзя.

## Пример

```python
priority_order([4, 2, 3, 2, 1, 9], [2, 4]) → [2, 2, 4, 1, 3, 9]
```
