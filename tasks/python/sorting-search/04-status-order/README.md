# Порядок строк в отчёте

В отчёте о прогоне сначала должны идти проблемные тесты. Статусы по важности: `"failed"`, `"flaky"`, `"skipped"`, `"passed"`. Внутри одного статуса тесты идут по имени, по алфавиту.

Напиши функцию `order_results(results)`: на входе список пар `(имя, статус)`, на выходе новый список этих пар в нужном порядке. Других статусов во входе нет.

## Пример

```
order_results([("b", "passed"), ("a", "failed"), ("c", "flaky"), ("a", "passed")])
  ->  [("a", "failed"), ("c", "flaky"), ("a", "passed"), ("b", "passed")]
```
