# Общий журнал из нескольких потоков

Каждый поток содержит целые временные метки по неубыванию. Объедини любое число потоков в один отсортированный список, сохранив все повторы. Пустые потоки допустимы.

Реализуй `merge_streams(streams)`. Входные коллекции менять нельзя.

## Пример

```python
merge_streams([[1, 4], [1, 3], [], [2]]) → [1, 1, 2, 3, 4]
```
