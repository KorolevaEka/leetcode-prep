# Медианная пара замеров

Для каждой пары разных позиций вычисляется абсолютная разность значений. Верни k-ю разность по возрастанию, учитывая повторяющиеся разности. В списке не менее двух целых чисел; 1 ≤ k ≤ n*(n-1)//2. Не строй список всех пар.

Реализуй `pair_distance(values, k)`. Входные коллекции менять нельзя.

## Пример

```python
pair_distance([1, 3, 1], 1) → 0
```

## Ограничения

Число элементов — до 20 000; повторный полный перебор пар для каждого значения расстояния не подходит.
