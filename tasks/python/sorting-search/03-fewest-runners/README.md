# Сколько времени займёт прогон

Есть список длительностей тестов `durations` (положительные целые, в минутах) и `runners` параллельных раннеров. Тесты нужно раздать подряд: первый раннер берёт несколько первых тестов, второй — следующие подряд и так далее (порядок менять нельзя, раннер может остаться без тестов). Прогон заканчивается, когда закончит самый загруженный раннер.

Напиши функцию `min_run_time(durations, runners)` — минимальное возможное время прогона.

## Пример

```
min_run_time([7, 2, 5, 10, 8], 2)  ->  18    # [7, 2, 5] и [10, 8]
min_run_time([1, 2, 3, 4], 4)      ->  4
min_run_time([5, 5, 5], 1)         ->  15
```

## Ограничения

`1 <= runners`, список не пустой. Ожидается решение быстрее полного перебора разбиений.
