# k-я метка в матрице

Строки и столбцы непустой прямоугольной матрицы целых чисел отсортированы по неубыванию. Верни k-е по величине в порядке возрастания значение, считая повторы отдельно; k начинается с 1. Не создавай плоскую отсортированную копию всей матрицы.

Реализуй `kth_matrix(matrix, k)`. Входные коллекции менять нельзя.

## Пример

```python
kth_matrix([[1, 5, 9], [10, 11, 13], [12, 13, 15]], 8) → 13
```
