# Сколько прогонов поместится

Выбери максимальное количество интервалов [start, end), которые не пересекаются. start < end, значения могут быть отрицательными. Соприкасающиеся интервалы совместимы; верни только количество.

Реализуй `max_nonoverlap(intervals)`. Входные коллекции менять нельзя.

## Пример

```python
max_nonoverlap([(0, 10), (1, 2), (2, 3), (3, 4)]) → 3
```
