# Версии в диапазоне

Версии — непустые строки из целых неотрицательных компонентов через точку. Завершающие нулевые компоненты не влияют на сравнение. Верни версии из закрытого диапазона [low, high] в порядке возрастания; эквивалентные версии сохраняют исходный порядок.

Реализуй `versions_between(versions, low, high)`. Входные коллекции менять нельзя.

## Пример

```python
versions_between(['1.2', '1.10', '1.2.0', '2'], '1.2', '1.10') → ['1.2', '1.2.0', '1.10']
```
