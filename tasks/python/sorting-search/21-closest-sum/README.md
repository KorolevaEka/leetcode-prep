# Тройка ближе всего к бюджету

В списке не менее трёх целых чисел. Найди сумму трёх разных позиций, ближайшую к target. При одинаковом расстоянии верни меньшую сумму.

Реализуй `closest_three(values, target)`. Входные коллекции менять нельзя.

## Пример

```python
closest_three([-1, 2, 1, -4], 1) → 2
```
