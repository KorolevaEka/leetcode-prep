# Резкие падения замеров

Посчитай пары i < j, для которых values[i] > 2*values[j]. Значения целые, в том числе отрицательные; равенство не подходит. Не перебирай каждую пару отдельно.

Реализуй `drop_pairs(values)`. Входные коллекции менять нельзя.

## Пример

```python
drop_pairs([1, 3, 2, 3, 1]) → 2
```
