# Поиск в сдвинутом индексе

Строго возрастающий список уникальных чисел циклически сдвинули. Верни индекс target или -1, если его нет. Разрешён двоичный поиск по исходному списку без восстановления сортировки.

Реализуй `rotated_index(values, target)`. Входные коллекции менять нельзя.

## Пример

```python
rotated_index([4, 5, 6, 7, 0, 1, 2], 0) → 4
```
