# Перцентиль времени ответа

Время ответа API измерили `n` раз. Перцентиль `p` (целое от 1 до 100) считаем по методу ближайшего ранга: упорядочи измерения по возрастанию, возьми ранг `ceil(p * n / 100)` (ранги считаются с 1) и верни измерение с этим рангом.

Напиши функцию `percentile(samples, p)`. Список не пустой. Исходный список менять нельзя.

## Пример

```
percentile([15, 20, 35, 40, 50], 30)   ->  20     # ранг ceil(1.5) = 2
percentile([15, 20, 35, 40, 50], 40)   ->  20     # ранг ceil(2.0) = 2
percentile([50, 15, 40, 20, 35], 100)  ->  50
```
