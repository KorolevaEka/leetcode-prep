# Добавить окно обслуживания

windows содержит непересекающиеся закрытые интервалы, отсортированные по началу. Добавь закрытый интервал new и объедини все пересечения, включая касание границ. Ответ — список кортежей по началу.

Реализуй `insert_window(windows, new)`. Входные коллекции менять нельзя.

## Пример

```python
insert_window([(1, 3), (6, 9)], (2, 7)) → [(1, 9)]
```
