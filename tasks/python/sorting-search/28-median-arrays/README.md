# Медиана двух архивов

Два списка целых значений отсортированы по неубыванию, суммарно в них хотя бы один элемент. Верни медиану их объединения: среднее двух центральных при чётной длине. Не сливай архивы в один список: найди границу двух половин двоичным поиском.

Реализуй `two_archive_median(a, b)`. Входные коллекции менять нельзя.

## Пример

```python
two_archive_median([1, 3], [2]) → 2
```
