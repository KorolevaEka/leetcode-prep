# Ближайшие события вокруг запроса

values отсортирован по неубыванию. Выбери k ближайших к target чисел (0 ≤ k ≤ len(values)); при одинаковом расстоянии предпочтительно меньшее число. Ответ верни по возрастанию, сохранив кратность.

Реализуй `nearest_k(values, target, k)`. Входные коллекции менять нельзя.

## Пример

```python
nearest_k([1, 2, 3, 4, 5], 3, 4) → [1, 2, 3, 4]
```
