# Вложенные контейнеры артефактов

Контейнер (width,height) помещается в другой только при строгом увеличении обеих сторон, поворачивать нельзя. Найди максимальную длину цепочки вложений из заданных контейнеров. Одинаковые размеры не дают дополнительный уровень.

Реализуй `nesting_depth(sizes)`. Входные коллекции менять нельзя.

## Пример

```python
nesting_depth([(5, 4), (6, 4), (6, 7), (2, 3)]) → 3
```
