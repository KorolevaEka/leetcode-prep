# Самые медленные тесты

Из отчёта о прогоне нужно вытащить `n` самых больших длительностей (в секундах), от большей к меньшей. Если тестов меньше `n`, верни все. Исходный список менять нельзя.

Напиши функцию `slowest(durations, n)`.

## Пример

```
slowest([3.2, 0.5, 9.1, 4.0], 2)  ->  [9.1, 4.0]
slowest([1, 2], 5)                ->  [2, 1]
slowest([4, 4, 1], 2)             ->  [4, 4]
```
