# Тесты буфера переупорядочивания

ReorderBuffer(start) ждёт последовательные целые номера от start. push(seq,value) сохраняет сообщение и возвращает список значений всей ставшей доступной непрерывной серии, сдвигая ожидание. Повтор уже выданного номера игнорируется; повтор ещё ожидающего номера сохраняет первое значение. Номера могут приходить в любом порядке.

Напиши pytest-тесты для указанного контракта. Используй только явные входные данные, без сети, реальных часов и файловой системы.

## Пример

```python
b=ReorderBuffer(1); b.push(2,"b") → []; b.push(1,"a") → ["a","b"]
```
