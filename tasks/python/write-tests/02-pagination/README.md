# Постраничная выдача

Функция `paginate(items, page, per_page)` возвращает элементы одной страницы: страницы нумеруются **с единицы**, на странице `per_page` элементов, последняя страница может быть неполной, а страница за пределами списка даёт пустой список. Если `page` или `per_page` меньше 1, функция выбрасывает `ValueError`.

Напиши тесты на pytest, которые проверят это поведение целиком — найдутся ошибки в границах страниц и в проверке аргументов.
