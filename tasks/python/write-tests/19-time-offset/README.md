# Тесты смещения часового пояса

Строка Z означает ноль. Иначе формат строго +HH:MM или -HH:MM с ASCII-цифрами, часы 00..23, минуты 00..59. Верни смещение в минутах, либо ValueError для неверной строки; знак относится к часам и минутам вместе.

Напиши pytest-тесты для указанного контракта. Используй только явные входные данные, без сети, реальных часов и файловой системы.

## Пример

```python
offset_minutes('+02:30') → 150
```
