# Тесты планировщика зависимостей

Scheduler(dependencies) получает словарь job → список предварительных jobs (все имена есть в словаре). claim() выбирает лексикографически первый ещё не выданный job с успешно завершёнными зависимостями, либо None. finish(job,ok) разрешён только для выданного незавершённого job, иначе ValueError. Ошибка блокирует зависимые jobs, но не независимые; циклы просто остаются неготовыми. Входные данные копируются.

Напиши pytest-тесты для указанного контракта. Используй только явные входные данные, без сети, реальных часов и файловой системы.

## Пример

```python
s=Scheduler({"a":[],"b":["a"]}); s.claim() → "a"
```
