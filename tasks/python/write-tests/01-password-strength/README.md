# Проверка надёжности пароля

Перед тобой функция `is_strong_password(password)` из формы регистрации. Пароль считается надёжным, если в нём **не меньше 8 символов**, есть **хотя бы одна цифра** и **хотя бы одна заглавная буква**. Код функции показан справа, его менять нельзя.

Напиши тесты на pytest, которые проверят все три правила. Твои тесты должны проходить на этой версии и ловить версии с ошибками.

## Подсказка

Для каждого правила нужен пароль, который нарушает только его: так видно, какая именно проверка сломана.
