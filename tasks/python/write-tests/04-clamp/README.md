# Тесты ограничителя значения

Функция возвращает value в закрытом диапазоне [low, high], заменяя слишком малые и большие значения соответствующей границей. При low > high возникает ValueError; числовые аргументы могут быть отрицательными.

Напиши pytest-тесты для указанного контракта. Используй только явные входные данные, без сети, реальных часов и файловой системы.

## Пример

```python
clamp(5, 0, 10) → 5
```
