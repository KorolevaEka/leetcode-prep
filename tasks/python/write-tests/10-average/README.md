# Тесты среднего без пропусков

В списке находятся числа и None. Верни среднее только чисел; при отсутствии чисел верни None. Ноль является полноценным замером.

Напиши pytest-тесты для указанного контракта. Используй только явные входные данные, без сети, реальных часов и файловой системы.

## Пример

```python
mean_present([0, 10, None]) → 5
```
