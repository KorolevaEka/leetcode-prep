# Тесты аренды блокировки с поколениями

LeaseLock выдаёт монотонно растущий токен при успешном acquire(owner,now,ttl), ttl > 0. Пока now < expires, любой acquire возвращает None, в том числе от текущего владельца. release(owner,token,now) освобождает только действующую аренду того же владельца и токена и возвращает bool. Ровно на expires старая аренда недействительна; токены после освобождения не переиспользуются.

Напиши pytest-тесты для указанного контракта. Используй только явные входные данные, без сети, реальных часов и файловой системы.

## Пример

```python
lock.acquire("a",0,5) → 1; lock.acquire("b",5,5) → 2
```
