# Тесты истечения кэша

Cache хранит значения по ключам. put(key,value,now,ttl) заменяет значение и срок действия, ttl ≥ 0. get(key,now) возвращает значение только пока now < время_записи+ttl, иначе None; чтение срок не продлевает. Часы передаются явно.

Напиши pytest-тесты для указанного контракта. Используй только явные входные данные, без сети, реальных часов и файловой системы.

## Пример

```python
c=Cache(); c.put("a", 3, 0, 2); c.get("a", 2) → None
```
