# Тесты повторов операции

Вызови operation без аргументов до первого успеха, повторяя только ValueError, не более attempts раз. Верни успешный результат, включая None или False. После исчерпания пробрось последнюю ошибку; другие исключения не перехватываются. attempts < 1 вызывает ValueError до первого вызова.

Напиши pytest-тесты для указанного контракта. Используй только явные входные данные, без сети, реальных часов и файловой системы.

## Пример

```python
retry(lambda: 7, 3) → 7
```
