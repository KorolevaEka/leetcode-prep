# Тесты автомата защиты от сбоев

Breaker(threshold,cooldown) изначально закрыт. call(operation,now) выполняет функцию: успех обнуляет число последовательных ошибок, ValueError увеличивает его и пробрасывается. После threshold ошибок автомат открыт: до now_ошибки+cooldown вызов отклоняется RuntimeError без запуска операции. Ровно на границе разрешён пробный вызов: успех закрывает автомат, ValueError заново открывает на полный cooldown. Время не убывает, threshold ≥ 1, cooldown > 0.

Напиши pytest-тесты для указанного контракта. Используй только явные входные данные, без сети, реальных часов и файловой системы.

## Пример

```python
b=Breaker(1,10); после ошибки в 0 пробный вызов разрешён в 10
```
