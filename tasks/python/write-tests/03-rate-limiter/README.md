# Лимитер запросов

Класс `RateLimiter(limit, window)` пропускает не больше `limit` запросов с одного ключа за скользящее окно в `window` секунд. Метод `allow(key, now)` возвращает `True`, если запрос принят (и тогда запоминает его), и `False`, если лимит исчерпан. Время `now` передаётся явно, поэтому тесты детерминированы.

Запрос, сделанный ровно `window` секунд назад, уже **вышел** из окна: например, при `window=10` запрос в момент `0` не учитывается в момент `10`, но учитывается в момент `9.9`. Отклонённые запросы лимит не занимают. У каждого ключа свой счётчик.

Напиши тесты на pytest, которые поймают ошибки в границе окна, числе допустимых запросов, учёте отклонённых запросов и разделении ключей.
