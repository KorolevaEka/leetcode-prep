# Тесты округления цены

Функция принимает строку Decimal-совместимого конечного десятичного числа и возвращает цену строкой с двумя знаками. Округление — ROUND_HALF_UP, включая отрицательные суммы. Отрицательный ноль выводится как 0.00; двоичный float не используется.

Напиши pytest-тесты для указанного контракта. Используй только явные входные данные, без сети, реальных часов и файловой системы.

## Пример

```python
rounded_price('2.675') → '2.68'
```
