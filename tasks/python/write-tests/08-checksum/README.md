# Тесты контрольной цифры

Строка состоит только из ASCII-цифр, включая пустую. Верни цифру 0..9, которую надо прибавить к сумме цифр, чтобы получить число, кратное 10. Пустая строка имеет контрольную цифру 0.

Напиши pytest-тесты для указанного контракта. Используй только явные входные данные, без сети, реальных часов и файловой системы.

## Пример

```python
check_digit('123') → 4
```
