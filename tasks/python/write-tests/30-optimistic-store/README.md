# Тесты атомарной записи по версии

VersionStore изначально пуст. read(key) возвращает (копия_значения, версия), для отсутствующего ключа (None,0). commit(changes,expected) атомарно проверяет версии всех ключей expected, требуя наличие ожидаемой версии каждого изменяемого ключа; конфликт возвращает False без записи. Успех копирует значения changes, увеличивает версии изменённых ключей на 1 и возвращает True. Ожидания могут включать ключи, которые не меняются.

Напиши pytest-тесты для указанного контракта. Используй только явные входные данные, без сети, реальных часов и файловой системы.

## Пример

```python
s=VersionStore(); s.commit({"x":1},{"x":0}) → True; s.read("x") → (1,1)
```
