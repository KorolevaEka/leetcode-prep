# Тесты идемпотентных переводов

Ledger(balances) копирует начальные неотрицательные балансы. transfer(id,source,target,amount) требует amount > 0, разных существующих счетов и достаточного баланса, иначе ValueError без изменений. Успех переводит средства и возвращает True. Точный повтор успешного id и параметров возвращает False; тот же id с другими параметрами вызывает ValueError. Неуспешный id не резервируется. balance(name) читает баланс.

Напиши pytest-тесты для указанного контракта. Используй только явные входные данные, без сети, реальных часов и файловой системы.

## Пример

```python
l=Ledger({"a":5,"b":0}); l.transfer("x","a","b",3) → True; повтор → False
```
