# Тесты кэша с обновлением давности

LRU(capacity), capacity ≥ 0, хранит значения: put(key,value) обновляет значение и делает ключ самым свежим; get(key) возвращает значение или None, успешное чтение тоже обновляет давность. При вставке нового ключа в полный кэш вытесняется давно не использованный. Нулевая вместимость ничего не хранит.

Напиши pytest-тесты для указанного контракта. Используй только явные входные данные, без сети, реальных часов и файловой системы.

## Пример

```python
c=LRU(1); c.put("a",1); c.put("b",2); c.get("a") → None
```
