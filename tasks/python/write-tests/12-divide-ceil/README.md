# Тесты числа партий

total — неотрицательное целое число объектов, size — положительная вместимость партии. Верни число партий, включая неполную последнюю; отрицательный total или size ≤ 0 вызывают ValueError.

Напиши pytest-тесты для указанного контракта. Используй только явные входные данные, без сети, реальных часов и файловой системы.

## Пример

```python
batch_count(10, 3) → 4
```
