# Тесты записи строки CSV

Сериализуй список строк в одну CSV-запись с запятыми и завершающим CRLF. Поле заключают в двойные кавычки, если оно содержит запятую, кавычку, CR или LF; внутреннюю кавычку удваивают. Единственное пустое поле тоже заключают в кавычки, пустой список даёт только CRLF.

Напиши pytest-тесты для указанного контракта. Используй только явные входные данные, без сети, реальных часов и файловой системы.

## Пример

```python
csv_row(['a,b', 'x"y', 'line\nnext']) → '"a,b","x""y","line\nnext"\r\n'
```
