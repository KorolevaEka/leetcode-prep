# Тесты пересечения интервалов

Интервалы a и b — пары (start,end), start ≤ end. Они полуоткрытые: конец не включён. Верни bool; пустой интервал ни с чем не пересекается.

Напиши pytest-тесты для указанного контракта. Используй только явные входные данные, без сети, реальных часов и файловой системы.

## Пример

```python
overlaps((0, 2), (1, 3)) → True
```
