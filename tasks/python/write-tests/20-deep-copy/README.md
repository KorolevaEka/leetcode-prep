# Тесты независимой копии JSON

Вход — JSON-совместимое значение. Верни равную по значениям глубокую копию словарей и списков; скаляры сохраняются. Изменение любого вложенного контейнера результата не должно менять оригинал.

Напиши pytest-тесты для указанного контракта. Используй только явные входные данные, без сети, реальных часов и файловой системы.

## Пример

```python
clone_json({"a":[1]}) → {"a":[1]}
```
