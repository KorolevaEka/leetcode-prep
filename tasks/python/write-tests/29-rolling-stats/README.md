# Тесты статистики последних замеров

RollingStats(capacity), capacity ≥ 1, хранит последние capacity числовых замеров в порядке add(value). snapshot() возвращает None для пустого окна или (count,minimum,maximum,mean,median). Для чётной длины медиана — среднее двух центральных. Чтение не меняет окно; одинаковые значения удаляются по одному.

Напиши pytest-тесты для указанного контракта. Используй только явные входные данные, без сети, реальных часов и файловой системы.

## Пример

```python
s=RollingStats(2); s.add(1); s.add(3); s.snapshot() → (2,1,3,2,2)
```
