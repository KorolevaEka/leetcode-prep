# Тесты бронирования стенда

Bookings хранит полуоткрытые интервалы бронирования. book(start,end) при start ≥ end вызывает ValueError, при пересечении возвращает False без записи, иначе записывает и возвращает True. cancel(start,end) удаляет точный интервал, возвращая True, либо False, если его нет.

Напиши pytest-тесты для указанного контракта. Используй только явные входные данные, без сети, реальных часов и файловой системы.

## Пример

```python
b=Bookings(); b.book(0,2) → True; b.book(2,3) → True
```
