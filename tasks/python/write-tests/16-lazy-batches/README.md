# Тесты ленивого разбиения потока

batches(source,size) возвращает генератор списков длиной size, последняя партия может быть короче. source — одноразовый итератор, size > 0. До запроса первой партии источник не читается, при каждом next читается только текущая партия. size ≤ 0 вызывает ValueError при первом next.

Напиши pytest-тесты для указанного контракта. Используй только явные входные данные, без сети, реальных часов и файловой системы.

## Пример

```python
list(batches(iter([1,2,3]),2)) → [[1,2],[3]]
```
