# Тесты точного фильтра тегов

Функция проверяет наличие тега в списке строк без учёта регистра. Внешние пробелы в каждом теге и wanted удаляются; сравнение точное, не по подстроке. Пустая строка тоже может быть тегом.

Напиши pytest-тесты для указанного контракта. Используй только явные входные данные, без сети, реальных часов и файловой системы.

## Пример

```python
has_tag([' API ', 'UI'], 'api') → True
```
