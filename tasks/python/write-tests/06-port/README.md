# Тесты номера порта

Строка после удаления внешних пробелов должна содержать только ASCII-цифры и задавать число от 1 до 65535 включительно. Верни int; знаки, пустые строки, Unicode-цифры и выход за границы вызывают ValueError.

Напиши pytest-тесты для указанного контракта. Используй только явные входные данные, без сети, реальных часов и файловой системы.

## Пример

```python
parse_port(' 443 ') → 443
```
