# Тесты ограниченной очереди

Queue(capacity) хранит FIFO-очередь, capacity ≥ 0. push(value) возвращает True при добавлении или False, если заполнена; отказ не меняет очередь. pop() возвращает самый старый элемент, а для пустой очереди вызывает IndexError. len(queue) показывает число элементов.

Напиши pytest-тесты для указанного контракта. Используй только явные входные данные, без сети, реальных часов и файловой системы.

## Пример

```python
q=Queue(1); q.push("a") → True; q.push("b") → False
```
