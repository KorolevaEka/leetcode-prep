# Тесты подписок во время доставки

subscribe(callback) возвращает уникальный токен, unsubscribe(token) возвращает bool. publish(value) вызывает подписчиков в порядке регистрации по снимку на начало этой публикации: удалённый внутри callback подписчик всё ещё получает текущее событие, новый ждёт следующего. Вложенная publish использует свой свежий снимок. Исключение callback останавливает доставку и пробрасывается.

Напиши pytest-тесты для указанного контракта. Используй только явные входные данные, без сети, реальных часов и файловой системы.

## Пример

```python
b.publish(value) вызывает снимок текущих подписчиков
```
