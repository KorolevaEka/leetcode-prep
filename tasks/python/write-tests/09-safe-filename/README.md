# Тесты безопасного имени файла

Замени каждый символ /, обратную косую черту и NUL на _. Все остальные символы, пробелы и регистр сохраняются. Пустая строка возвращается без изменений.

Напиши pytest-тесты для указанного контракта. Используй только явные входные данные, без сети, реальных часов и файловой системы.

## Пример

```python
safe_filename('a/b\\c') → 'a_b_c'
```
