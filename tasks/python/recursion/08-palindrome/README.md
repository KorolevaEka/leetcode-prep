# Симметрия списка шагов

Проверь, совпадает ли список строк steps со своим обратным порядком. Пустой список и один шаг симметричны. Сравнивай значения точно, с учётом регистра.

Реализуй `is_mirror(steps)`. Входные коллекции менять нельзя.

## Пример

```python
is_mirror(['a', 'b', 'a']) → True
```
