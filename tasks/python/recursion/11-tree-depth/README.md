# Глубина дерева наборов

Дерево — словарь с ключом children, содержащим список таких же узлов. У листа children пуст, его глубина 1. Для None верни 0; вычисли максимальную глубину дерева.

Реализуй `suite_depth(tree)`. Входные коллекции менять нельзя.

## Пример

```python
suite_depth({'children': [{'children': []}, {'children': [{'children': []}]}]}) → 3
```
