# Все достижимые суммы затрат

Верни отсортированный список различных сумм, которые можно получить, выбрав любое подмножество позиций целочисленного списка. Пустое подмножество даёт 0; значения могут быть отрицательными.

Реализуй `subset_sums(costs)`. Входные коллекции менять нельзя.

## Пример

```python
subset_sums([1, 2, 2]) → [0, 1, 2, 3, 4, 5]
```
