# Очистка одинаковых блоков

За одну операцию удаляется непрерывная группа из k одинаковых целых меток, награда k². После удаления соседи смыкаются. Найди наибольшую суммарную награду за полную очистку; пустой список даёт 0. Длина не больше 30.

Реализуй `cleanup_score(colors)`. Входные коллекции менять нельзя.

## Пример

```python
cleanup_score([1, 3, 2, 2, 2, 3, 4, 3, 1]) → 23
```
