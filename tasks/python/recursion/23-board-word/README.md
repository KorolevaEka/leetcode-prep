# Маршрут слова по сетке

В прямоугольной сетке символов найди путь, читающий word. Двигаться можно вверх, вниз, влево и вправо, каждую клетку разрешено посетить не более одного раза за путь. Верни bool; пустое слово есть даже в пустой сетке.

Реализуй `word_route(board, word)`. Входные коллекции менять нельзя.

## Пример

```python
word_route([['A', 'B', 'C', 'E'], ['S', 'F', 'C', 'S'], ['A', 'D', 'E', 'E']], 'ABCCED') → True
```
