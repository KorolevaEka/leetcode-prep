# Наследование настроек в дереве

Узел имеет name, settings (словарь строковых ключей и целых значений) и children. Настройки узла перекрывают унаследованные, затем передаются детям. Верни пары (name, полный_словарь) в прямом обходе слева направо; None даёт [].

Реализуй `effective_settings(tree, inherited)`. Входные коллекции менять нельзя.

## Пример

```python
effective_settings({'name': 'r', 'settings': {'a': 1}, 'children': [{'name': 'x', 'settings': {'a': 0}, 'children': []}]}, {'b': 2}) → [('r', {'b': 2, 'a': 1}), ('x', {'b': 2, 'a': 0})]
```
