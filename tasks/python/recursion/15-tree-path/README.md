# Путь к тесту в дереве

Узел имеет строковое name и список children. Верни список имён от корня до первого узла с именем target при обходе детей слева направо, либо None. Совпадение с корнем разрешено; дерево может быть None.

Реализуй `find_suite_path(tree, target)`. Входные коллекции менять нельзя.

## Пример

```python
find_suite_path({'name': 'root', 'children': [{'name': 'x', 'children': [{'name': 'a', 'children': []}]}]}, 'a') → ['root', 'x', 'a']
```
