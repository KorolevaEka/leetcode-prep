# Равная загрузка нескольких воркеров

Раздели положительные целые стоимости на k непустых групп с одинаковой суммой. Каждая позиция используется ровно один раз; верни bool. k ≥ 1, при пустом списке ответ False.

Реализуй `equal_buckets(costs, k)`. Входные коллекции менять нельзя.

## Пример

```python
equal_buckets([4, 3, 2, 3, 5, 2, 1], 4) → True
```
