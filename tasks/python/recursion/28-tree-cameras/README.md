# Минимум датчиков в дереве

Двоичное дерево задано None или тройкой (имя,left,right). Датчик в узле покрывает сам узел, его родителя и непосредственных детей. Найди минимальное число датчиков для покрытия всех узлов; пустому дереву датчики не нужны.

Реализуй `tree_cameras(tree)`. Входные коллекции менять нельзя.

## Пример

```python
tree_cameras((0, (0, None, None), (0, None, None))) → 1
```
