# Общий шаг периодических проверок

Два неотрицательных целых числа задают интервалы периодических проверок. Найди их наибольший общий делитель; хотя бы одно число положительно. Используй рекурсивное сокращение задачи.

Реализуй `common_step(a, b)`. Входные коллекции менять нельзя.

## Пример

```python
common_step(18, 24) → 6
```
