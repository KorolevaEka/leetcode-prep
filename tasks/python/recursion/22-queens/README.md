# Расстановка независимых агентов

Размести n агентов на доске n×n: по одному в строке и столбце, без общих диагоналей. Верни все размещения как списки номеров столбцов по строкам, лексикографически. Для n=0 ответ [[]].

Реализуй `queen_placements(n)`. Входные коллекции менять нельзя.

## Пример

```python
queen_placements(4) → [[1, 3, 0, 2], [2, 0, 3, 1]]
```
