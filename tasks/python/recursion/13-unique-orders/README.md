# Все различные порядки параметров

Верни все разные перестановки целых values, отсортированные лексикографически, в виде списка списков. Для пустого списка ответ [[]]; одинаковые значения не создают одинаковых ответов.

Реализуй `unique_orders(values)`. Входные коллекции менять нельзя.

## Пример

```python
unique_orders([1, 1, 2]) → [[1, 1, 2], [1, 2, 1], [2, 1, 1]]
```
