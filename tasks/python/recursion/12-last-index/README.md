# Последнее вхождение в цепочке

Найди индекс последнего вхождения target в список items, либо -1. Используй рекурсивную проверку более короткого префикса; сравнение точное.

Реализуй `last_position(items, target)`. Входные коллекции менять нельзя.

## Пример

```python
last_position(['a', 'b', 'a'], 'a') → 2
```
