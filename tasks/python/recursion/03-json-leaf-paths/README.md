# Пути до значений в JSON

Чтобы сравнить два ответа API, их «разворачивают» в список путей до значений. Ответ — вложенные словари и списки. Путь собирается так: ключи словаря через точку, индекс списка в квадратных скобках: `user.tags[1]`, `items[0].id`. Листом считается любое значение, кроме непустого словаря или непустого списка: число, строка, `None`, `False`, а также пустой `{}` и пустой `[]`.

Напиши функцию `leaf_paths(data)`, где `data` — словарь, и верни список путей в порядке обхода. Для пустого словаря верни `[]`.

## Пример

```
leaf_paths({"id": 7, "user": {"name": "Ann", "tags": ["a", "b"]}, "items": [{"id": 1}], "note": None})
  ->  ["id", "user.name", "user.tags[0]", "user.tags[1]", "items[0].id", "note"]
leaf_paths({"a": {}, "b": [], "c": 0})  ->  ["a", "b", "c"]
```
