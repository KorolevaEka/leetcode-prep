# Зеркало двоичного дерева

Двоичное дерево задано None или тройкой (value,left,right), где поддеревья имеют тот же формат. Создай дерево с переставленными левым и правым потомками на каждом уровне; значения не меняются.

Реализуй `mirror_tree(tree)`. Входные коллекции менять нельзя.

## Пример

```python
mirror_tree((1, (2, None, (4, None, None)), (3, None, None))) → (1, (3, None, None), (2, (4, None, None), None))
```
