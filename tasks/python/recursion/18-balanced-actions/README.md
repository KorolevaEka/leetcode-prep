# Все корректные пары действий

Построй все строки из n открывающих и n закрывающих круглых скобок, которые корректны по вложенности. Ответ отсортирован лексикографически; n ≥ 0, для нуля ответ [""].

Реализуй `paired_actions(n)`. Входные коллекции менять нельзя.

## Пример

```python
paired_actions(3) → ['((()))', '(()())', '(())()', '()(())', '()()()']
```
