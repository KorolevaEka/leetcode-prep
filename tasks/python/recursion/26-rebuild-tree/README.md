# Восстановить дерево запуска

Два списка уникальных строковых имён задают прямой обход (корень, левое, правое) и симметричный обход (левое, корень, правое) одного двоичного дерева. Верни дерево из троек (name,left,right), пустой узел None. Гарантируется согласованность входов.

Реализуй `rebuild_tree(preorder, inorder)`. Входные коллекции менять нельзя.

## Пример

```python
rebuild_tree(['a', 'b', 'd', 'c'], ['b', 'd', 'a', 'c']) → ('a', ('b', None, ('d', None, None)), ('c', None, None))
```
