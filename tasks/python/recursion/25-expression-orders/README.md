# Все результаты расстановки скобок

Строка содержит неотрицательные целые числа без пробелов, разделённые +, - или *. Верни отсортированный список результатов всех способов расставить бинарные скобки, сохраняя порядок чисел и операций. Одинаковые результаты от разных способов повторяются. eval и готовые вычислители запрещены.

Реализуй `expression_results(expression)`. Входные коллекции менять нельзя.

## Пример

```python
expression_results('2*3-4*5') → [-34, -14, -10, -10, 10]
```
