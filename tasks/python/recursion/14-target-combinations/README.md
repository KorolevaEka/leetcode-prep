# Наборы тестов с точным бюджетом

Каждый положительный cost можно использовать не больше одного раза. Верни уникальные неубывающие наборы с суммой target, отсортированные лексикографически. target ≥ 0; для нулевой цели единственный ответ — пустой набор.

Реализуй `budget_combinations(costs, target)`. Входные коллекции менять нельзя.

## Пример

```python
budget_combinations([10, 1, 2, 7, 6, 1, 5], 8) → [[1, 1, 6], [1, 2, 5], [1, 7], [2, 6]]
```
