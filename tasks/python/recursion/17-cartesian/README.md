# Матрица параметризованного запуска

Каждая ось содержит допустимые значения параметра. Верни все комбинации в виде списков в порядке вложенных циклов по осям. Пустой набор осей даёт [[]], а пустая отдельная ось — [].

Реализуй `parameter_matrix(axes)`. Входные коллекции менять нельзя.

## Пример

```python
parameter_matrix([[1, 2], ['a', 'b']]) → [[1, 'a'], [1, 'b'], [2, 'a'], [2, 'b']]
```
