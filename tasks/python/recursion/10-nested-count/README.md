# Количество числовых замеров

Данные состоят из вложенных списков и целых чисел. Посчитай количество чисел независимо от глубины; пустые списки не считаются замерами. Вход не содержит циклов.

Реализуй `measurement_count(data)`. Входные коллекции менять нельзя.

## Пример

```python
measurement_count([[1, 2], [], [3, [4]]]) → 4
```
