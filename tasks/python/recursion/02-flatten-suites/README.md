# Развернуть вложенные наборы

Наборы тестов могут содержать другие наборы на любой глубине: `["smoke", ["auth", ["login", "logout"]], "cart"]`. Напиши функцию `flatten(items)`, которая возвращает плоский список всех строк в порядке слева направо. Пустые вложенные списки ничего не добавляют. Исходная структура не меняется.

## Пример

```
flatten(["smoke", ["auth", ["login", "logout"]], "cart"])  ->  ["smoke", "auth", "login", "logout", "cart"]
flatten([[], ["a"], [[]]])                                  ->  ["a"]
flatten([])                                                 ->  []
```
