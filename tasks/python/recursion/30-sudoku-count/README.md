# Количество решений мини-судоку

Доска 4×4 содержит числа 0..4, где 0 — пустая клетка. Заполни её так, чтобы каждая строка, столбец и блок 2×2 содержали 1,2,3,4 по одному разу. Верни число решений; неверные исходные подсказки дают 0. Исходную доску менять нельзя.

Реализуй `sudoku_count(board)`. Входные коллекции менять нельзя.

## Пример

```python
sudoku_count([[1, 2, 3, 4], [3, 4, 1, 2], [2, 1, 4, 3], [4, 3, 2, 0]]) → 1
```
