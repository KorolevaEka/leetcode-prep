# Сумма цифр номера прогона

Номер прогона — неотрицательное целое. Для «контрольной суммы» нужна сумма его цифр. Напиши рекурсивную функцию `sum_digits(n)`: сумма отделяет последнюю цифру и вызывает себя для остальной части числа.

## Пример

```
sum_digits(1234)  ->  10
sum_digits(10)    ->  1
sum_digits(7)     ->  7
sum_digits(0)     ->  0
```
