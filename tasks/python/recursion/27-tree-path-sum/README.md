# Максимальная сумма пути по дереву

Двоичное дерево — None или тройка (целое значение,left,right). Путь идёт по рёбрам без повторного посещения узла, может начинаться и заканчиваться где угодно и обязан содержать хотя бы один узел. Верни максимальную сумму; для None ответ None.

Реализуй `max_tree_path(tree)`. Входные коллекции менять нельзя.

## Пример

```python
max_tree_path((-10, (9, None, None), (20, (15, None, None), (7, None, None)))) → 42
```
