# Четыре набора погрешностей

У четырёх независимых замеров есть наборы отклонений: списки целых чисел `a`, `b`, `c`, `d`. Нужно посчитать, сколько существует четвёрок индексов `(i, j, k, l)`, для которых `a[i] + b[j] + c[k] + d[l] == 0`. Разные индексы — разные четвёрки, даже если значения совпадают.

Напиши функцию `count_quads(a, b, c, d)`. В каждом списке до 300 элементов, значения могут быть отрицательными. Перебор всех четвёрок слишком медленный.

## Пример

```
count_quads([1, 2], [-2, -1], [-1, 2], [0, 2])  ->  2
count_quads([0], [0], [0], [0])                 ->  1
count_quads([], [1], [1], [1])                  ->  0
```
