# Общие теги наборов

У каждого набора тестов есть список тегов. Напиши функцию `common_tags(suites)`, которая возвращает теги, встречающиеся в каждом наборе, по алфавиту и без повторов. Если наборов нет, результат пустой. Теги внутри набора могут повторяться.

## Пример

```
common_tags([["api", "smoke", "fast"], ["smoke", "ui", "api"], ["api", "smoke"]])  ->  ["api", "smoke"]
common_tags([["a"], ["b"]])                                                         ->  []
common_tags([["z", "z", "a"]])                                                      ->  ["a", "z"]
common_tags([])                                                                     ->  []
```
