# Тесты по наборам

Имя теста в отчёте имеет вид `"<набор>.<тест>"`, например `"auth.login_ok"`. Имя самого теста может тоже содержать точки: `"auth.token.expired"` — это набор `auth` и тест `token.expired`; набор — всё до первой точки.

Напиши функцию `group_by_suite(names)`, которая возвращает словарь «набор → список имён тестов (без префикса набора)». Порядок наборов и порядок тестов внутри — как в исходном списке. Имена без точки считай относящимися к набору `"misc"`, имя теста остаётся целым.

## Пример

```
group_by_suite(["auth.login", "cart.add", "auth.token.expired", "smoke"])
  ->  {"auth": ["login", "token.expired"], "cart": ["add"], "misc": ["smoke"]}
```
