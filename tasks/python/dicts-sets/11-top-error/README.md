# Самая частая ошибка

По списку сообщений об ошибках нужно понять, что ломается чаще всего. Напиши функцию `top_error(errors)`, которая возвращает самое частое сообщение. Если несколько сообщений встречаются одинаково часто, верни то, что появилось в списке раньше. Для пустого списка верни `None`.

## Пример

```
top_error(["timeout", "404", "timeout", "500"])  ->  "timeout"
top_error(["b", "a", "a", "b"])                  ->  "b"
top_error([])                                    ->  None
```
