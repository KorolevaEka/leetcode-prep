# Отрезки замеров с нужной суммой

Нагрузочный тест записал отклонения времени ответа от нормы: положительные и отрицательные числа в миллисекундах. Нужно посчитать, сколько существует непустых отрезков подряд идущих замеров, сумма которых ровно `k`. Отрезки с разными границами считаются разными, даже если состоят из одинаковых чисел.

Напиши функцию `count_spans(values, k)`. В списке может быть до 200 000 элементов, значения целые и могут быть отрицательными или нулевыми.

## Пример

```
count_spans([1, 2, 3], 3)     ->  2     # [1, 2] и [3]
count_spans([1, -1, 0], 0)    ->  3     # [1, -1], [1, -1, 0] и [0]
count_spans([], 0)            ->  0
```
