# Два теста в одно окно

В ночное окно нужно уложить ровно два теста, чтобы вместе они заняли `slot` секунд. Напиши функцию `find_pair(durations, slot)`, которая возвращает пару индексов `(i, j)`, `i < j`, для которой `durations[i] + durations[j] == slot`. Один и тот же тест (индекс) дважды брать нельзя, а две разные позиции с одинаковой длительностью можно. Если подходящих пар несколько, выбери ту, у которой `j` минимален, а среди них ту, где минимален `i`. Если пары нет, верни `None`.

Длительности неотрицательные; в списке могут быть тысячи элементов, так что перебор всех пар не подойдёт.

## Пример

```
find_pair([4, 8, 6, 1], 10)    ->  (0, 2)
find_pair([2, 7, 3, 8], 10)    ->  (1, 2)
find_pair([5, 3], 10)          ->  None
find_pair([5], 10)             ->  None
find_pair([5, 5], 10)          ->  (0, 1)
```
