# Уникальные ошибки по порядку

В логе много повторяющихся сообщений об ошибках. Напиши функцию `unique_in_order(messages)`, которая возвращает список без повторов, сохраняя порядок первого появления каждого сообщения. Регистр и пробелы значимы: `"Timeout"` и `"timeout"` — разные сообщения. Исходный список менять не нужно.

## Пример

```
unique_in_order(["timeout", "500", "timeout", "404", "500"])  ->  ["timeout", "500", "404"]
unique_in_order(["a", "a", "a"])                              ->  ["a"]
unique_in_order([])                                           ->  []
```
