# Нестабильные тесты

CI запускает тесты много раз, результат каждого запуска — пара `(имя теста, прошёл ли он)`. Тест называют нестабильным, если среди его запусков есть и успешные, и упавшие. Тест, который всегда падает или всегда проходит, нестабильным не считается.

Напиши функцию `flaky_tests(runs)`, возвращающую имена нестабильных тестов в порядке их первого появления в списке запусков, без повторов.

## Пример

```
runs = [("login", True), ("cart", False), ("login", False), ("pay", True), ("cart", False), ("pay", True)]
flaky_tests(runs)  ->  ["login"]
flaky_tests([("a", False), ("a", False)])  ->  []
```
