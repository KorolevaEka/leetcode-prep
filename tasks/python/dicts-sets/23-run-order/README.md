# Порядок запуска с зависимостями

`deps` — словарь «имя теста → список тестов, которые должны пройти раньше». Нужно вернуть порядок запуска всех тестов. Тест можно ставить в порядок, когда все его предусловия уже стоят. Если готовы сразу несколько тестов, первым идёт тот, чьё имя меньше по алфавиту. Имена, которые встречаются только в списках предусловий, тоже запускаются; предусловий у них нет. Одно и то же предусловие может быть записано в списке несколько раз.

Если порядка не существует (цикл, в том числе тест, зависящий от самого себя), выбрось `ValueError`. Готовый `graphlib` не подойдёт: он не гарантирует нужный порядок среди готовых тестов.

Напиши функцию `run_order(deps)`.

## Пример

```
run_order({"login": [], "cart": ["login", "catalog"]})  ->  ["catalog", "login", "cart"]
run_order({"a": ["b"], "b": ["a"]})                     ->  ValueError
```
