# Сводка статусов

После прогона набора тестов у каждого теста есть статус — строка вроде `"passed"` или `"failed"`. Напиши функцию `count_statuses(statuses)`, которая возвращает словарь «статус → сколько раз он встретился». Статусы, которых нет в списке, в словарь попадать не должны.

## Пример

```
count_statuses(["passed", "failed", "passed"])  ->  {"passed": 2, "failed": 1}
count_statuses(["skipped"])                     ->  {"skipped": 1}
count_statuses([])                              ->  {}
```
