# Какие тесты можно запускать

У каждого теста могут быть предусловия: тесты, которые должны успешно пройти раньше. Они записаны словарём «тест → список предусловий». Известен список уже пройденных тестов `done`.

Напиши функцию `ready_tests(deps, done)`, которая возвращает тесты из `deps`, готовые к запуску: сам тест ещё не пройден, а все его предусловия пройдены. Тест без предусловий готов, если не пройден. Предусловие может отсутствовать среди ключей `deps` — это просто имя, оно считается выполненным, только если есть в `done`. Порядок результата — как в `deps`.

## Пример

```
deps = {"cart": ["login"], "pay": ["login", "cart"], "login": [], "logout": ["login"]}
ready_tests(deps, ["login"])          ->  ["cart", "logout"]
ready_tests(deps, [])                 ->  ["login"]
ready_tests({"a": ["setup"]}, [])     ->  []
```
