# Новые падения после правок

Есть два списка имён упавших тестов: из прошлого прогона (`previous`) и из текущего (`current`). Напиши функцию `new_failures(previous, current)`, которая возвращает тесты, упавшие сейчас, но не падавшие раньше. Порядок — как в `current`, каждое имя не более одного раза (в списке имя может повторяться, если тест перезапускали). Исходные списки менять не нужно.

## Пример

```
new_failures(["login", "cart"], ["cart", "pay", "search", "pay"])  ->  ["pay", "search"]
new_failures(["a"], ["a", "a"])                                    ->  []
new_failures([], ["b", "a"])                                       ->  ["b", "a"]
```
