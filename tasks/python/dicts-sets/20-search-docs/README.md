# Поиск по заметкам

В базе заметок по тестированию каждая заметка — пара «id → текст». Напиши функцию `search_docs(docs, query)`, которая возвращает id заметок, в которых встречаются все слова запроса. Слово — это фрагмент между пробельными символами; регистр не важен; слово ищется целиком (`log` не совпадает с `login`), а порядок слов и их повторы не важны. Результат отсортирован по id. Если в запросе нет слов, верни пустой список.

## Пример

```
docs = {"n1": "Login fails on Safari", "n2": "login ok, logs rotated", "n3": "safari login SLOW"}
search_docs(docs, "login safari")  ->  ["n1", "n3"]
search_docs(docs, "log")           ->  []
search_docs(docs, "   ")           ->  []
```
