# Левое соединение двух выгрузок

Есть две выгрузки тестовых данных: пользователи (`left`) и их заказы (`right`), обе — списки словарей, общее поле называется `key`. Напиши функцию `left_join(left, right, key)`, которая для каждой строки слева (в исходном порядке) возвращает объединённые словари:

- для каждой строки справа с тем же значением `key` — один результат `{**строка_слева, **строка_справа}` (если имена полей совпадают, побеждает правая строка), справа строки идут в исходном порядке;
- если подходящих строк справа нет — одна копия строки слева без изменений.

Строки без поля `key` ни с чем не соединяются: слева они остаются как есть, справа игнорируются. Входные списки и словари менять не нужно.

## Пример

```
users  = [{"id": 1, "name": "Ann"}, {"id": 2, "name": "Bob"}]
orders = [{"id": 1, "sum": 5}, {"id": 1, "sum": 7}]
left_join(users, orders, "id")
    ->  [{"id": 1, "name": "Ann", "sum": 5}, {"id": 1, "name": "Ann", "sum": 7}, {"id": 2, "name": "Bob"}]
```
