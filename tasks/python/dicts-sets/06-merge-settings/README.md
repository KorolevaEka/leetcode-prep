# Настройки окружения с переопределениями

У тестового стенда есть настройки по умолчанию, а у конкретного прогона — переопределения. Напиши функцию `merge_settings(defaults, overrides)`, которая возвращает новый словарь: значения из `overrides` перекрывают `defaults`, а ключ, у которого в `overrides` стоит `None`, из результата удаляется (даже если его не было в `defaults`). Остальные значения, в том числе `0`, `False` и `""`, обычные. Входные словари менять не нужно.

## Пример

```
merge_settings({"retries": 3, "env": "qa"}, {"retries": 0, "debug": True})
    ->  {"retries": 0, "env": "qa", "debug": True}
merge_settings({"proxy": "p1", "env": "qa"}, {"proxy": None})
    ->  {"env": "qa"}
```
