# Самый длинный диапазон номеров

В выгрузке лежат номера тест-кейсов в произвольном порядке, возможны повторы. Нужно найти самый длинный диапазон подряд идущих целых номеров (каждый следующий на единицу больше предыдущего), которые все присутствуют в выгрузке. Повторяющийся номер считается один раз. Если самых длинных диапазонов несколько, нужен тот, что начинается с меньшего номера.

Напиши функцию `longest_run(ids)`, она возвращает список номеров диапазона по возрастанию; для пустого списка — пустой список. Номеров может быть до 200 000; числа могут быть отрицательными.

## Пример

```
longest_run([7, 3, 4, 100, 5, 4, 6])  ->  [3, 4, 5, 6, 7]
longest_run([1, 2, 10, 11])           ->  [1, 2]
longest_run([])                       ->  []
```
