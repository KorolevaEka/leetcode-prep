# Дубли в тестовых пользователях

В базе тестовых данных накопились дубликаты пользователей: один и тот же email записан с разным регистром и лишними пробелами. Пользователь — словарь `{"id": int, "email": str}`.

Напиши функцию `find_duplicates(users)`, которая возвращает список групп дублей. Группа — список `id` пользователей с одинаковым email (после обрезки пробелов по краям и приведения к нижнему регистру); в ответ попадают только группы из двух и более пользователей. Внутри группы `id` идут в порядке исходного списка, сами группы — в порядке первого появления их email.

## Пример

```
users = [
    {"id": 1, "email": "Ann@Test.io"},
    {"id": 2, "email": "bob@test.io"},
    {"id": 3, "email": " ann@test.io "},
    {"id": 4, "email": "BOB@test.io"},
    {"id": 5, "email": "zed@test.io"},
]
find_duplicates(users)  ->  [[1, 3], [2, 4]]
```
