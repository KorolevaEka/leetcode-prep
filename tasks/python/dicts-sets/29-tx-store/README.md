# Хранилище со вложенными транзакциями

Тестовому стенду нужно хранилище «ключ → значение» с транзакциями, которые можно вкладывать друг в друга. Реализуй класс `TxStore`:

- `set(key, value)`, `delete(key)`, `get(key)` — значение или `None`, если ключа нет. Изменения видны сразу, внутри открытой транзакции тоже;
- `begin()` — открывает новую транзакцию поверх текущей;
- `rollback()` — отменяет изменения только самой внутренней открытой транзакции;
- `commit()` — закрывает самую внутреннюю транзакцию и оставляет её изменения в силе: они становятся частью внешней транзакции (и откатываются вместе с ней), а если внешней нет, применяются окончательно.

`commit()` и `rollback()` без открытой транзакции выбрасывают `ValueError`. `delete` несуществующего ключа ничего не делает.

## Пример

```
s = TxStore()
s.set("a", 1)
s.begin()
s.set("a", 2)
s.begin()
s.delete("a")
s.get("a")      ->  None
s.rollback()
s.get("a")      ->  2
s.commit()
s.get("a")      ->  2
```
