# Склейка дублей тестовых аккаунтов

В тестовой базе накопились дубли: каждый аккаунт — это список email-адресов. Если у двух аккаунтов есть хотя бы один общий адрес, это один человек; цепочка тоже склеивает: если A делит адрес с B, а B с C, то A, B и C — один человек. Адреса сравниваются как обычные строки.

Верни список групп: в каждой группе все адреса склеенных аккаунтов без повторов по возрастанию, сами группы отсортированы по возрастанию (как списки строк). Пустые аккаунты игнорируются.

Напиши функцию `merge_accounts(accounts)`.

## Пример

```
merge_accounts([["a@x", "b@x"], ["c@x"], ["b@x", "d@x"]])  ->  [["a@x", "b@x", "d@x"], ["c@x"]]
merge_accounts([[], ["z@x"]])                               ->  [["z@x"]]
```
