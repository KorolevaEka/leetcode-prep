# Отрезки ровно с k разными кодами

В логе подряд идут коды ответов сервера. Нужно посчитать, сколько существует непустых отрезков подряд идущих записей, в которых ровно `k` разных кодов. Отрезки с разными границами считаются разными. При `k = 0` ответ 0.

Напиши функцию `count_exact_distinct(codes, k)`. Записей до 100 000, кодов — целых чисел — может быть мало, а может быть много.

## Пример

```
count_exact_distinct([1, 2, 1, 2, 3], 2)  ->  7
count_exact_distinct([1, 1, 1], 1)        ->  6
count_exact_distinct([1, 2], 3)           ->  0
```
