# Конфиг с историей значений

Нужно воспроизвести, какой конфиг действовал в прошлый момент времени. Реализуй класс `VersionedConfig`:

- `set(key, value, t)` — с момента `t` у ключа значение `value`;
- `delete(key, t)` — с момента `t` ключа нет;
- `get(key, t)` — значение, действовавшее в момент `t`, или `None`, если ключа тогда ещё не было или он был удалён.

Запись, сделанная в момент `t`, видна уже при запросе `get(key, t)`. Если по ключу несколько записей (в том числе `delete`) в один и тот же момент, действует последняя из них по порядку вызовов. Моменты времени в вызовах `set` и `delete` не убывают, а `get` можно вызывать с любым `t`, в том числе из прошлого. Тесты делают по 100 000 вызовов.

## Пример

```
c = VersionedConfig()
c.set("timeout", 5, 10)
c.set("timeout", 8, 20)
c.get("timeout", 15)   ->  5
c.get("timeout", 20)   ->  8
c.get("timeout", 9)    ->  None
```
