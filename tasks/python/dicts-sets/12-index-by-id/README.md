# Словарь тестовых записей по id

Из API приходит список записей — словарей с полем `"id"`. Чтобы быстро находить запись по id, напиши функцию `index_by_id(items)`, которая возвращает словарь «id → запись целиком». Если один id встречается несколько раз, остаётся последняя запись. Записи без поля `"id"` пропускаются.

## Пример

```
index_by_id([{"id": 1, "n": "a"}, {"id": 2, "n": "b"}, {"id": 1, "n": "c"}])
    ->  {1: {"id": 1, "n": "c"}, 2: {"id": 2, "n": "b"}}
index_by_id([{"n": "no id"}])  ->  {}
```
