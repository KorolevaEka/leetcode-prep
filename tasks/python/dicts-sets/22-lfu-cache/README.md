# Кэш с вытеснением редко используемых

Кэшу ответов нужно вытеснять то, что используют реже всего. Реализуй класс `LfuCache`:

- `LfuCache(capacity)` — максимум `capacity` ключей;
- `get(key)` — значение или `None`, если ключа нет; успешный `get` считается использованием;
- `put(key, value)` — кладёт значение. Для существующего ключа заменяет значение и тоже считается использованием. Если ключ новый, а кэш полон, сначала вытесняется ключ с наименьшим числом использований; при равенстве — тот, к которому обращались давнее всего.

Вставка нового ключа считается одним использованием. Вытесненный ключ при возвращении начинает счёт заново. При `capacity = 0` кэш ничего не хранит. Все операции должны работать быстро: тесты делают по 100 000 операций.

## Пример

```
c = LfuCache(2)
c.put("a", 1)
c.get("a")        ->  1        # a использован дважды
c.put("b", 2)
c.put("c", 3)                   # вытеснен b: он использован реже a
c.get("b")        ->  None
```
