# Статистика по эндпоинтам

Нагрузочный прогон записал вызовы API: `(эндпоинт, время ответа в мс)`. Напиши функцию `endpoint_stats(calls)`, которая возвращает для каждого эндпоинта словарь с четырьмя числами: `"count"` — число вызовов, `"min"` и `"max"` — наименьшее и наибольшее время, `"total"` — сумма времён. Эндпоинты, которых не было в вызовах, в ответ не попадают; для пустого списка ответ пустой.

## Пример

```
endpoint_stats([("/login", 120), ("/cart", 80), ("/login", 40), ("/login", 200)])
    ->  {"/login": {"count": 3, "min": 40, "max": 200, "total": 360},
         "/cart":  {"count": 1, "min": 80, "max": 80,  "total": 80}}
```
