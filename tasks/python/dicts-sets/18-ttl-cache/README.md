# Кэш токенов с временем жизни

Тестовому набору нужен кэш токенов, которые протухают. Реализуй класс `TtlCache`:

- `TtlCache(ttl)` — время жизни значения в секундах;
- `set(key, value, now)` — кладёт значение, `now` — текущее время (число, передаётся снаружи, чтобы тесты не ждали);
- `get(key, now)` — возвращает значение или `None`, если ключа нет или значение уже протухло.

Значение, записанное в момент `t`, живёт, пока `now < t + ttl`; в момент `t + ttl` оно уже недоступно. Повторный `set` по тому же ключу заменяет значение и отсчитывает срок заново от нового `now`. Чтение срок не продлевает. Время только растёт.

## Пример

```
cache = TtlCache(10)
cache.set("token", "abc", now=100)
cache.get("token", now=109)   ->  "abc"
cache.get("token", now=110)   ->  None
cache.get("other", now=0)     ->  None
```
