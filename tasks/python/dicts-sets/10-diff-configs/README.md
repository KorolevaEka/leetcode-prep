# Что изменилось в конфиге

Перед выкладкой стенда сравнивают старый и новый конфиг. Напиши функцию `diff_configs(old, new)`, которая возвращает словарь с тремя списками ключей, каждый по алфавиту: `"added"` — ключи только в `new`, `"removed"` — только в `old`, `"changed"` — ключи есть в обоих, но значения разные. Все три ключа в ответе есть всегда, даже если списки пустые.

## Пример

```
diff_configs({"a": 1, "b": 2, "c": 3}, {"b": 20, "c": 3, "d": 4})
    ->  {"added": ["d"], "removed": ["a"], "changed": ["b"]}
diff_configs({}, {})  ->  {"added": [], "removed": [], "changed": []}
```
