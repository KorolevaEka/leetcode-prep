# Заголовок без учёта регистра

В HTTP имена заголовков не зависят от регистра, но в словаре из тестового клиента они приходят как попало: `"content-type"`, `"Content-Type"`, `"CONTENT-TYPE"`. Напиши функцию `header_value(headers, name)`, которая возвращает значение заголовка `name` без учёта регистра. Если в словаре несколько ключей, отличающихся только регистром, верни значение того, что идёт в словаре первым. Если заголовка нет, верни `None`.

## Пример

```
header_value({"Content-Type": "text/html"}, "content-type")        ->  "text/html"
header_value({"x-id": "1", "X-ID": "2"}, "X-Id")                   ->  "1"
header_value({"Accept": "*/*"}, "Content-Type")                    ->  None
```
