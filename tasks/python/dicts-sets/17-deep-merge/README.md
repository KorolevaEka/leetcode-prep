# Слияние вложенных настроек

Настройки стенда вложенные: `{"db": {"host": "x", "port": 1}, "debug": False}`. Напиши функцию `deep_merge(base, override)`, которая возвращает новый словарь. Правила: если по одному ключу в обоих словарях лежат словари, они сливаются так же, рекурсивно; в остальных случаях (числа, строки, списки, `None`, словарь против не-словаря) побеждает значение из `override`. Ключи, которых нет в `override`, остаются как в `base`.

Исходные словари менять нельзя, и результат не должен делить с ними вложенные словари и списки: правка результата не должна менять `base` и `override`.

## Пример

```
base     = {"db": {"host": "qa", "port": 5432}, "tags": ["a"], "debug": False}
override = {"db": {"port": 6000}, "tags": ["b"], "retries": 3}
deep_merge(base, override)
    ->  {"db": {"host": "qa", "port": 6000}, "tags": ["b"], "debug": False, "retries": 3}
```
