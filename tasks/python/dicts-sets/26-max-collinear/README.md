# Замеры на одной прямой

Нагрузочный тест записал точки `(нагрузка, время ответа)`, оба числа целые. Нужно найти наибольшее число точек, лежащих на одной прямой. Совпадающие точки — это отдельные замеры, и каждый считается. Если точек не больше двух, ответ — их количество.

Напиши функцию `max_collinear(points)`. Точек до 800, координаты до по модулю 10⁹, поэтому дробные числа с плавающей точкой не подойдут: на таких координатах они путают разные прямые.

## Пример

```
max_collinear([(0, 0), (1, 2), (2, 4), (5, 1)])  ->  3
max_collinear([(3, 3), (3, 3), (3, 3)])          ->  3
max_collinear([])                                ->  0
```
