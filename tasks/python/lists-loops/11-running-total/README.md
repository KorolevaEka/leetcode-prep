# Накопленное время прогона

После каждого теста нужно показывать, сколько секунд прошло с начала прогона. Напиши функцию `running_total(durations)`, где `durations` — длительности тестов по порядку. Верни список той же длины: на позиции `i` стоит сумма первых `i + 1` длительностей.

## Пример

```
running_total([3, 1, 4])  ->  [3, 4, 8]
running_total([5])        ->  [5]
running_total([])         ->  []
```
