# Сколько раз тест мигнул

Нестабильный тест при каждом прогоне может поменять результат. Список `results` — статусы одного теста по порядку запусков, каждый `"passed"` или `"failed"`. Напиши функцию `count_flips(results)`, которая возвращает, сколько раз статус отличался от статуса предыдущего прогона.

## Пример

```
count_flips(["passed", "failed", "failed", "passed"])  ->  2
count_flips(["failed", "failed"])                       ->  0
count_flips(["passed"])                                 ->  0
count_flips([])                                         ->  0
```
