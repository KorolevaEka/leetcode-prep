# Минимум переходов по шагам

Из позиции i разрешено перейти вперёд на любое число от 1 до reach[i]. Верни минимальное число переходов от первого шага к последнему, либо -1, если путь закрыт. Пустая последовательность и один шаг требуют 0 переходов.

Реализуй `min_jumps(reach)`. Входные коллекции менять нельзя.

## Пример

```python
min_jumps([2, 3, 1, 1, 4]) → 2
```
