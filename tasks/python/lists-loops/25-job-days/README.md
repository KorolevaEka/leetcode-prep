# Разбить прогон по дням

Разбей список положительных сложностей на days непустых подряд идущих групп. Стоимость дня — максимум сложности в группе; минимизируй сумму стоимостей. При невозможном числе дней верни -1; для пустого списка и days=0 ответ 0.

Реализуй `min_day_cost(costs, days)`. Входные коллекции менять нельзя.

## Пример

```python
min_day_cost([6, 5, 4, 3, 2, 1], 2) → 7
```
