# Сдвиг очереди запусков

Очередь запусков прокручивают: первые `k` элементов уезжают в конец, порядок остальных сохраняется. Напиши функцию `rotate_left(queue, k)`, которая возвращает новый список, а переданный не меняет. `k` может быть больше длины очереди (тогда прокрутка идёт по кругу) и может быть отрицательным (тогда очередь сдвигается вправо). Пустая очередь остаётся пустой.

## Пример

```
rotate_left(["a", "b", "c", "d"], 1)   ->  ["b", "c", "d", "a"]
rotate_left(["a", "b", "c", "d"], 6)   ->  ["c", "d", "a", "b"]
rotate_left(["a", "b", "c", "d"], -1)  ->  ["d", "a", "b", "c"]
rotate_left([], 3)                     ->  []
```
