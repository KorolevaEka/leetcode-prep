# Два сборщика артефактов

Два робота стартуют в верхних углах прямоугольной непустой таблицы неотрицательных наград. Каждый шаг переводит обоих в следующую строку с изменением столбца на -1, 0 или 1. Награды посещённых клеток суммируются; если роботы попали в одну клетку, её награда учитывается один раз. Найди максимальную награду после достижения нижней строки.

Реализуй `collected_artifacts(grid)`. Входные коллекции менять нельзя.

## Пример

```python
collected_artifacts([[3, 1, 1], [2, 5, 1], [1, 5, 5], [2, 1, 1]]) → 24
```
