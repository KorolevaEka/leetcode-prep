# Партии для запуска

Тесты нужно запустить партиями фиксированного размера. Напиши функцию `split_batches(tests, size)`, которая режет список `tests` на последовательные партии по `size` штук с сохранением порядка. Последняя партия может быть короче. Для пустого списка верни пустой список.

## Пример

```
split_batches(["a", "b", "c", "d", "e"], 2)  ->  [["a", "b"], ["c", "d"], ["e"]]
split_batches(["a", "b"], 5)                 ->  [["a", "b"]]
split_batches([], 3)                         ->  []
```

## Ограничения

`size >= 1`.
