# Пики нагрузки

Во время нагрузочного прогона раз в секунду записывали число одновременных пользователей. Пиком считается секунда, в которую пользователей строго больше, чем и в предыдущую, и в следующую. Первая и последняя секунды пиками не бывают: у них нет соседа с одной из сторон. Плато (несколько равных значений подряд) пиком не считается.

Напиши функцию `find_peaks(load)`, которая возвращает индексы пиков по возрастанию.

## Пример

```
find_peaks([1, 5, 2, 7, 3])  ->  [1, 3]
find_peaks([1, 4, 4, 2])     ->  []
find_peaks([9, 1, 9])        ->  []
find_peaks([])               ->  []
```
