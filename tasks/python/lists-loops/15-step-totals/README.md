# Итоги по шагам сценария

Каждый прогон сценария — это список времени шагов в секундах. Прогон мог оборваться, поэтому списки разной длины: если шага нет в записи, значит, до него дело не дошло. Нужно узнать суммарное время каждого шага по всем прогонам.

Напиши функцию `step_totals(runs)`, которая возвращает список сумм: на позиции `i` стоит сумма `i`-х шагов тех прогонов, где такой шаг есть. Длина результата равна длине самого длинного прогона. Без прогонов результат пустой.

## Пример

```
step_totals([[1, 2, 3], [4, 5], [6]])  ->  [11, 7, 3]
step_totals([[2, 2]])                  ->  [2, 2]
step_totals([[], [5]])                 ->  [5]
step_totals([])                        ->  []
```
