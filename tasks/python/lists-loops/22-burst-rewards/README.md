# Порядок очистки стенда

На стенде стоят модули с положительными целыми весами. Удаление модуля приносит произведение его веса и весов ближайших ещё не удалённых соседей; отсутствующий сосед имеет вес 1. Выбери порядок удаления всех модулей с максимальной суммой награды.

Реализуй `max_cleanup(rewards)`. Входные коллекции менять нельзя.

## Пример

```python
max_cleanup([3, 1, 5, 8]) → 167
```
