# Паузы между повторами

Упавший запрос повторяют с нарастающими паузами: первая пауза равна `base` секунд, каждая следующая вдвое длиннее предыдущей, но не больше `cap` секунд. Напиши функцию `retry_delays(retries, base, cap)`, которая возвращает список пауз для `retries` повторов. Если повторов нет, верни пустой список.

## Пример

```
retry_delays(4, 1, 100)  ->  [1, 2, 4, 8]
retry_delays(5, 3, 20)   ->  [3, 6, 12, 20, 20]
retry_delays(0, 1, 10)   ->  []
```

## Ограничения

`base` и `cap` положительные, `base <= cap`.
