# Лучший участок кругового расписания

Список целых выгод образует кольцо. Найди максимальную сумму непустого непрерывного участка, разрешая переход с конца в начало и используя каждую позицию не более одного раза. Для пустого списка верни 0.

Реализуй `circular_gain(values)`. Входные коллекции менять нельзя.

## Пример

```python
circular_gain([5, -3, 5]) → 10
```
