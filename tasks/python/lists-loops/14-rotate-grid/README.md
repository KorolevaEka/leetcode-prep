# Поворот карты стенда

Расположение устройств на тестовом стенде записано матрицей: `grid[r][c]` — устройство в ряду `r` на месте `c`. Все ряды одной длины, но матрица не обязательно квадратная. Чтобы нарисовать карту «со стороны двери», её нужно повернуть на 90 градусов по часовой стрелке.

Напиши функцию `rotate_grid(grid)`, которая возвращает новую повёрнутую матрицу и не меняет исходную. Пустая матрица остаётся пустой.

## Пример

```
rotate_grid([["a", "b", "c"],
             ["d", "e", "f"]])  ->  [["d", "a"],
                                     ["e", "b"],
                                     ["f", "c"]]
rotate_grid([["x"]])            ->  [["x"]]
rotate_grid([])                 ->  []
```
