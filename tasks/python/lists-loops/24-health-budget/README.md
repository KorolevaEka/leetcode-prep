# Запас энергии для маршрута

Прямоугольная непустая таблица содержит прибавки и потери энергии, включая стартовую и конечную клетки. Двигаться можно только вправо и вниз; энергия после каждой клетки должна быть хотя бы 1. Найди минимальную начальную энергию.

Реализуй `initial_energy(grid)`. Входные коллекции менять нельзя.

## Пример

```python
initial_energy([[-2, -3, 3], [-5, -10, 1], [10, 30, -5]]) → 7
```
