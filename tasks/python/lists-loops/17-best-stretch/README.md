# Лучший отрезок смены

После каждого прогона известно, насколько изменилась доля успешных тестов: `+3`, `-2`, `0`. Нужно найти непрерывный отрезок прогонов, на котором суммарное улучшение максимально. Отрезок не может быть пустым: даже если все изменения отрицательные, нужно вернуть наименее плохой отрезок.

Напиши функцию `best_stretch(deltas)`, возвращающую кортеж `(start, end, total)`: индексы первого и последнего прогона отрезка (оба включительно) и его сумму. Если лучших отрезков несколько, выбери тот, у которого `start` меньше; при равном `start` — тот, у которого меньше `end`. Список непустой. Решение должно работать за один проход: длина списка до десятков тысяч.

## Пример

```
best_stretch([2, -1, 3, -5, 4])  ->  (0, 2, 4)
best_stretch([-3, -1, -2])       ->  (1, 1, -1)
best_stretch([1, -1, 1])         ->  (0, 0, 1)
```
