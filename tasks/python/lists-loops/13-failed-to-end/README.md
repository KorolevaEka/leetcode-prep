# Упавшие в конец очереди

В очереди на перезапуск лежат результаты тестов: словари вида `{"name": "login", "status": "failed"}`, статус `"passed"`, `"failed"` или `"skipped"`. Нужно перенести все упавшие тесты в конец очереди. Относительный порядок упавших между собой и порядок всех остальных остаётся прежним.

Напиши функцию `move_failed_last(results)`, которая меняет **переданный список на месте** и ничего не возвращает (`None`). Сами словари менять и копировать нельзя: в списке должны остаться те же объекты.

## Пример

```
results = [{"name": "a", "status": "failed"}, {"name": "b", "status": "passed"},
           {"name": "c", "status": "failed"}, {"name": "d", "status": "skipped"}]
move_failed_last(results)
# имена в списке теперь: ["b", "d", "a", "c"]
```
