# Партии по бюджету времени

Тесты нужно запустить несколькими партиями, чтобы одна партия не шла дольше `limit` секунд. Тесты идут в заданном порядке и нельзя менять их местами. Правило жадное: очередной тест кладётся в текущую партию, если суммарное время партии с ним не превысит `limit`; иначе он открывает новую партию. Тест, который один длиннее `limit`, всё равно запускается: он занимает отдельную партию.

Напиши функцию `plan_batches(durations, limit)`, возвращающую список партий (списков длительностей). Пустых партий быть не должно. Длительности положительные.

## Пример

```
plan_batches([4, 3, 3, 5, 2], 7)  ->  [[4, 3], [3], [5, 2]]
plan_batches([3, 12, 3], 10)      ->  [[3], [12], [3]]
plan_batches([5, 5], 10)          ->  [[5, 5]]
plan_batches([], 10)              ->  []
```
