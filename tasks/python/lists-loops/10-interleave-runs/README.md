# Чередование двух прогонов

Две машины прогнали тесты и вернули списки имён. Чтобы сравнить их глазами, нужно свести их в один список: сначала первый элемент первой машины, затем первый второй, потом второй первой и так далее. Когда один список заканчивается, оставшиеся элементы другого идут в конец по порядку.

Напиши функцию `interleave(a, b)`.

## Пример

```
interleave(["a1", "a2"], ["b1", "b2"])        ->  ["a1", "b1", "a2", "b2"]
interleave(["a1", "a2", "a3"], ["b1"])        ->  ["a1", "b1", "a2", "a3"]
interleave([], ["b1", "b2"])                  ->  ["b1", "b2"]
```
