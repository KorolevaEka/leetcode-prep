# Дни замедления

Каждую ночь запускают один и тот же набор тестов и записывают общую длительность в минутах. Нужно находить дни замедления: день `i` — замедление, если его длительность **строго больше** 1.5 средней длительности всех предыдущих дней. Для самого первого дня предыдущих дней нет, поэтому он замедлением не бывает. Сам день в своё среднее не входит.

Напиши функцию `slowdown_days(durations)`, возвращающую номера дней (с нуля) по возрастанию.

## Пример

```
slowdown_days([10, 10, 16, 10])  ->  [2]
slowdown_days([10, 15])          ->  []      # 15 = ровно 1.5 * 10, не больше
slowdown_days([4, 2, 2, 20])     ->  [3]
slowdown_days([7])               ->  []
```

Длительности — целые неотрицательные числа.
