# Пропущенные номера прогонов

CI должен был прогнать сборки с номерами от `lo` до `hi` включительно, но в журнале остались не все. Список `found` — номера, которые нашлись: отсортированы по возрастанию, без повторов, все лежат в промежутке `[lo, hi]`. Нужно описать, чего не хватает.

Напиши функцию `missing_ranges(found, lo, hi)`, возвращающую список строк по возрастанию. Подряд идущие пропущенные номера записываются как `"a-b"`, а пропуск из одного номера — просто `"a"`.

## Пример

```
missing_ranges([3, 4, 7], 1, 9)  ->  ["1-2", "5-6", "8-9"]
missing_ranges([1, 2, 3], 1, 3)  ->  []
missing_ranges([2, 4], 1, 5)     ->  ["1", "3", "5"]
missing_ranges([], 5, 8)         ->  ["5-8"]
```
