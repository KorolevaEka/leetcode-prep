# Карусель воркера

Один воркер выполняет тесты по кругу. В очереди тесты стоят в порядке номеров `0, 1, 2, ...`. Воркер берёт тест из начала очереди и выполняет его не дольше `quantum` секунд. Если тест уложился, он закончен. Если ему нужно больше времени, он ставится в конец очереди с оставшимся временем, а воркер берёт следующий.

Напиши функцию `finish_order(durations, quantum)`, возвращающую номера тестов в том порядке, в котором они закончились. `durations[i]` — сколько секунд нужно тесту `i`, все положительные, `quantum >= 1`.

## Пример

```
finish_order([5, 2, 4], 3)  ->  [1, 0, 2]
finish_order([3, 3], 3)     ->  [0, 1]
finish_order([1], 10)       ->  [0]
finish_order([], 2)         ->  []
```

Тест `0` получает 3 секунды и остаётся ждать ещё 2, тест `1` заканчивается за один ход, тест `2` получает 3 секунды и остаётся ждать ещё 1; затем тест `0` доделывается, а последним заканчивается тест `2`.
