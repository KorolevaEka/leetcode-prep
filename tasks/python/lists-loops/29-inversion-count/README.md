# Сколько перестановок в очереди

Идентификаторы должны идти по возрастанию. Посчитай пары позиций i < j, для которых ids[i] > ids[j]. Равные значения не считаются нарушением; пустая очередь даёт 0.

Реализуй `inversion_count(ids)`. Входные коллекции менять нельзя.

## Пример

```python
inversion_count([3, 1, 2]) → 2
```

## Ограничения

Число элементов — до 30 000; нужен алгоритм быстрее полного перебора пар.
