# Ресурс с днём охлаждения

В день можно купить один ресурс или продать ранее купленный, одновременно хранится не больше одного. После продажи следующий день покупать нельзя. Найди максимальную прибыль по неотрицательным ценам; незавершённая покупка не приносит прибыль.

Реализуй `max_trade(prices)`. Входные коллекции менять нельзя.

## Пример

```python
max_trade([1, 2, 3, 0, 2]) → 3
```
