# Порядок склейки матриц

Матрицы имеют размеры dims[0]×dims[1], dims[1]×dims[2] и так далее. Умножение a×b на b×c стоит a*b*c операций. Выбери расстановку скобок с минимальной стоимостью; менять порядок матриц нельзя. Размеры положительные, при числе матриц меньше двух стоимость 0.

Реализуй `matrix_cost(dims)`. Входные коллекции менять нельзя.

## Пример

```python
matrix_cost([10, 30, 5, 60]) → 4500
```
