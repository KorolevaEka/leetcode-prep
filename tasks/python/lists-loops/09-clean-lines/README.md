# Чистка файла с данными

Файл с тестовыми данными читают построчно. Пустые строки и строки из одних пробелов нужно выбросить. Комментарием считается строка, у которой первый непробельный символ `#`, такие тоже выбрасываем. У остальных строк убери пробелы по краям.

Напиши функцию `clean_lines(lines)`, возвращающую оставшиеся строки в исходном порядке.

## Пример

```
clean_lines(["  user=anna ", "", "# note", "   ", "mode=fast"])  ->  ["user=anna", "mode=fast"]
clean_lines(["  # note", "a # b"])                              ->  ["a # b"]
clean_lines([])                                                  ->  []
```
