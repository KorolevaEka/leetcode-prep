# Средняя длительность прогона

У тебя есть длительности тестов в секундах. Напиши функцию `average_duration(durations)`, которая возвращает среднее значение, округлённое до двух знаков после запятой. Для пустого списка верни `0.0`.

## Пример

```
average_duration([1.5, 2.5, 4])  ->  2.67
average_duration([3])            ->  3.0
average_duration([])             ->  0.0
```
