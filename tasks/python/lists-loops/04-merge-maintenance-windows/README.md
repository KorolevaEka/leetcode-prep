# Окна обслуживания

Тестовый стенд недоступен в окнах обслуживания, каждое — пара `[начало, конец]` в минутах от полуночи. Окна приходят в произвольном порядке и могут пересекаться, вкладываться друг в друга или касаться (конец одного равен началу другого — это одно непрерывное окно).

Напиши функцию `merge_windows(windows)`, которая возвращает список объединённых окон, отсортированный по началу. Входной список менять нельзя.

## Пример

```
merge_windows([[60, 90], [10, 30], [25, 40]])  ->  [[10, 40], [60, 90]]
merge_windows([[0, 10], [10, 20]])             ->  [[0, 20]]
merge_windows([[0, 100], [10, 20]])            ->  [[0, 100]]
merge_windows([])                              ->  []
```
