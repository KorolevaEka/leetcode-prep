# Прямоугольник на графике нагрузки

Каждый замер — столбик ширины 1 и неотрицательной высоты. Найди максимальную площадь прямоугольника, целиком лежащего под соседними столбиками; пустой график даёт 0.

Реализуй `largest_block(heights)`. Входные коллекции менять нельзя.

## Пример

```python
largest_block([2, 1, 5, 6, 2, 3]) → 10
```

## Ограничения

Число столбиков — до 30 000; полный перебор всех отрезков не подходит.
