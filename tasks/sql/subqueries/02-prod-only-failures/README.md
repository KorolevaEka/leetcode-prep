# Падения на prod без проверки на staging

Каждый прогон (`test_runs`) относится к сборке (`build_id`; у части прогонов она не указана — `NULL`), окружению и имеет статус.

Найди версии сборок (`version`), у которых: был прогон `failed` в окружении `prod`, **и** не было ни одного прогона в `staging` (любого статуса). Порядок строк не важен.

## Пример

```
сборка A: prod failed, staging passed   -> нет (на staging проверяли)
сборка B: prod failed, staging нет      -> B
сборка C: prod passed                   -> нет (не падала)
```
