# Медленнее среднего

В `test_results` у каждого результата есть длительность в миллисекундах.

Выведи `test_name` и `duration_ms` у результатов, чья длительность **строго больше средней** по всей таблице. Равные среднему не берём. Порядок строк не важен.

## Пример

```
длительности: 100, 200, 600  (среднее 300)
  -> выводим только строку с 600
```
