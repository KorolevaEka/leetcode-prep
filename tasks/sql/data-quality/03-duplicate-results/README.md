# Лишние дубли результатов

Из-за ретраев загрузчика в `test_results` один и тот же результат мог записаться несколько раз. Бизнес-ключ результата — пара `(test_run_id, test_case_id)`: в прогоне у кейса должна быть одна запись.

Для чистки нужен список записей на удаление: оставляем **самую раннюю** запись (с наименьшим `test_result_id`) в каждой паре, а все остальные — лишние. Выведи `test_result_id` лишних записей. Порядок строк не важен.

## Пример

```
test_result_id  test_run_id  test_case_id        лишние:
4               2            1                   6 и 9
6               2            1                   (запись 4 — самая ранняя, остаётся)
9               2            1
```
