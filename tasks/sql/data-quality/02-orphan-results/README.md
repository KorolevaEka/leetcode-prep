# Результаты без прогона

Результаты в `test_results` загрузили импортом без проверки ссылок (внешнего ключа нет). Нужно найти «осиротевшие» результаты: `test_run_id` указан, но такого прогона в `test_runs` **нет**.

Результат, у которого `test_run_id` пустой (`NULL`), сиротой не считается — это отдельная проблема.

Выведи `test_result_id, test_run_id`. Порядок строк не важен.

## Пример

```
test_runs: 1, 2
test_results: (id 10, run 1), (id 11, run 9), (id 12, run NULL)
  -> 11  9
```
