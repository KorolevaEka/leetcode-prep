# Дубли в тестовых пользователях

В таблице `users` лежат тестовые аккаунты. Адреса `QA.Bot@example.com` и `qa.bot@example.com` — один и тот же адрес, регистр не важен.

Найди адреса, которые встречаются **больше одного раза**. Выведи `email` (в нижнем регистре) и `copies` — сколько записей с этим адресом. Порядок строк не важен.

## Пример

```
email                 email                copies
QA.Bot@example.com    qa.bot@example.com   2
qa.bot@example.com
ops@example.com       (один раз — не выводим)
```
