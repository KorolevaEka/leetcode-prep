# Два самых долгих теста в наборе

В таблице `test_cases` у каждого теста есть набор (`suite`) и длительность (`duration_ms`).

Для каждого набора выведи тесты с **первым и вторым местом по длительности** (`suite, name, duration_ms`). Если несколько тестов разделили место — выводи всех: при длительностях 1200, 900, 900, 300 в выдачу попадут первые три. Места считаются как в спорте: после ничьей следующее место пропускается. Если два теста делят первое место, следующий за ними получает **третье** и не попадает в выдачу. Порядок строк не важен.

## Пример

```
auth:    login 1200, register 900, logout 900, reset 300
  -> login (1 место), register и logout (оба 2 место)
reports: export 3000, import 3000, view 100
  -> export и import (оба 1 место); view — 3 место, не выводим
```
