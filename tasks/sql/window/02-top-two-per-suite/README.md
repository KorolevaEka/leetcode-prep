# Два самых долгих теста в наборе

В таблице `test_cases` у каждого теста есть набор (`suite`) и длительность (`duration_ms`).

Для каждого набора выведи тесты с **первым и вторым местом по длительности** (`suite, name, duration_ms`). Если несколько тестов разделили место — выводи всех: при длительностях 1200, 900, 900, 300 в выдачу попадут первые три. Порядок строк не важен.

## Пример

```
auth: login 1200, register 900, logout 900, reset 300
  -> login (1 место), register и logout (2 место, делят)
```
