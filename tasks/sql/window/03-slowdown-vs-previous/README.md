# Замедление относительно прошлой сборки

В `test_results` для каждого кейса и сборки сохранена длительность. Сборки идут по времени (`builds.built_on`).

Найди случаи, когда тест в сборке стал **более чем на 50% медленнее**, чем в предыдущей сборке **того же теста**: `duration_ms > 1.5 × прошлая`. Ровно в полтора раза — ещё не замедление. Для первой сборки теста сравнивать не с чем.

Выведи `name, version, prev_ms, duration_ms`. Порядок строк не важен.

## Пример

```
checkout: 4.1 -> 450 мс, 4.2 -> 900 мс
  -> checkout  4.2  450  900     (900 > 675)
```
