# Окружения с падениями за неделю

В `test_runs` названия окружений вводили вручную, поэтому `Staging`, `staging` и `STAGING` — одно и то же окружение.

Выведи список **различных** окружений (в нижнем регистре, колонка `env`), где был хотя бы один прогон со статусом `failed`, начатый с 1 по 7 марта 2024 **включительно, до конца суток 7 марта**. Окружения `local` и `dev` в любом регистре не считай. Порядок строк не важен.

## Пример

```
env      status  started_at                 env
Staging  failed  2024-03-01 09:00   ->      staging
staging  failed  2024-03-04 14:30
Local    failed  2024-03-03 11:00           (local не считаем)
qa       failed  2024-03-08 00:00           (уже вне периода)
```
