# Проблемные запросы API v2

В таблице `api_requests` — журнал вызовов API: путь, метод, HTTP-код ответа и задержка в миллисекундах.

Найди запросы **версии v2** (путь начинается с `/api/v2/`), у которых либо код ответа 500 и выше, либо задержка строго больше 1500 мс. Выведи `api_request_id, path, status_code, latency_ms`. Порядок строк не важен.

Осторожно: путь `/api/v20/ping` — это уже не v2.

## Пример

```
path           status_code latency_ms          api_request_id
/api/v2/users  500         80           ->     (эта строка)
/api/v2/users  200         120                 (нет: всё в порядке)
/health        200         5000                (нет: не v2)
```
