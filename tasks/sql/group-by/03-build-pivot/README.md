# Сводка статусов по сборкам

Для отчёта о качестве нужна «развёртка» статусов по сборкам. Данные лежат в `builds`, `test_runs` и `test_results`.

Для каждой сборки, где **есть хотя бы один упавший результат**, выведи:
`version`, `passed`, `failed`, `skipped` — число результатов с этим статусом, и `pass_rate` — процент прошедших среди **выполненных** (passed + failed; пропущенные не считаются), округлённый до одного знака после запятой.

Порядок строк не важен.

## Пример

```
сборка 3.1.0: 1 passed, 3 failed, 1 skipped
  -> 3.1.0  1  3  1  25.0       (1 / (1 + 3) = 25%)
```
