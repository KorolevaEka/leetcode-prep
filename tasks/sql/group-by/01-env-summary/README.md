# Сводка по окружениям

В `test_results` — результаты запусков тестов по окружениям; один и тот же кейс мог выполняться в окружении много раз.

Для каждого окружения выведи: `env`, `results` — сколько всего результатов, `distinct_cases` — сколько **разных** тест-кейсов запускали, `slowest_ms` — самую большую длительность. Порядок строк не важен.

## Пример

```
env      test_case_id  duration_ms          env      results  distinct_cases  slowest_ms
staging  1             400          ->      staging  3        2               1200
staging  1             450
staging  2             1200
```
