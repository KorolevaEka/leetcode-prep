# Кандидаты в нестабильные

Тест считается кандидатом в нестабильные, если его запускали **минимум 4 раза** и доля упавших запусков **строго больше 25%**. Три запуска из трёх — слишком мало данных, а ровно 25% — ещё нормально.

По `test_results` выведи для каждого такого кейса: `name`, `runs` — число запусков, `failed` — сколько из них упало. Порядок строк не важен.

## Пример

```
checkout: 4 запуска, 2 упало  (50%)       name      runs  failed
login:    8 запусков, 2 упало (25%)  ->   checkout  4     2
export:   3 запуска, 3 упало
```
