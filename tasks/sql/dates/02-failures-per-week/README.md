# Падения по неделям

В `test_results` у каждого результата есть момент выполнения `executed_at`.

Посчитай упавшие результаты (`failed`) по неделям. Неделя начинается в **понедельник**; в колонке `week_start` — дата этого понедельника (формат даты, без времени), в `failures` — число падений. Недели без падений выводить не нужно. Порядок строк не важен.

## Пример

```
2024-03-03 (воскресенье) failed  ->  неделя с 2024-02-26
2024-03-04 (понедельник) failed  ->  неделя с 2024-03-04
```
