# Нарушения SLA по дефектам

Дефекты хранятся в `defects`: время открытия, время закрытия (`NULL`, если ещё открыт) и серьёзность. SLA — **48 часов** на исправление. Отчёт строится на момент **2024-04-01 00:00**: для открытых дефектов время жизни — от открытия до этого момента.

Для каждой серьёзности (`severity`) выведи:
- `closed` — сколько дефектов закрыто;
- `avg_hours` — среднее время исправления закрытых в часах, округлённое до одного знака;
- `sla_breaches` — сколько дефектов нарушили SLA: прожили **строго больше** 48 часов (закрытые — до закрытия, открытые — до момента отчёта).

Порядок строк не важен.

## Пример

```
открыт 03-05 10:00, закрыт 03-07 10:00  (ровно 48 ч)   -> не нарушение
открыт 03-20 08:00, всё ещё открыт                    -> нарушение
```
