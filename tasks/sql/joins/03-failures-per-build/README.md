# Падения по сборкам, включая нулевые

У каждой сборки (`builds`) может быть несколько прогонов (`test_runs`), в прогоне — результаты (`test_results`). Есть сборки, на которых ничего не запускали.

Для **каждой** сборки выведи `version` и `failed_count` — число результатов со статусом `failed` по всем её прогонам. Если падений нет или прогонов не было — `0`. Порядок строк не важен.

## Пример

```
version  прогоны          результаты             version  failed_count
2.0.0    2 прогона        3 failed        ->     2.0.0    3
2.0.1    1 прогон         все passed             2.0.1    0
2.1.1    прогонов нет                            2.1.1    0
```
