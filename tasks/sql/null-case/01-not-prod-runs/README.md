# Прогоны не на prod

В `test_runs` у части прогонов окружение не указано (`env IS NULL`) — запустили из старого скрипта.

Выведи `test_run_id` всех прогонов, **которые не на prod**. Прогон без указанного окружения под это тоже подходит: про него точно нельзя сказать, что он на prod. Порядок строк не важен.

## Пример

```
env       test_run_id
prod      (нет)
staging   (да)
NULL      (да)
```
