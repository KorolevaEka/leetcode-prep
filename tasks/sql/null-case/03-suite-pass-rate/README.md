# Процент прохождения по наборам

В `test_results` у результатов статусы `passed`, `failed`, `skipped`, а иногда статус вообще не заполнен (`NULL`).

Для каждого набора (`suite`) выведи:
- `executed` — сколько тестов **выполнено** (`passed` или `failed`; пропущенные и без статуса не считаются);
- `pass_rate` — процент `passed` среди выполненных, округлённый до одного знака. Если в наборе ни один тест не выполнялся — `pass_rate` должен быть `NULL`, а не ошибкой деления на ноль и не нулём.

Порядок строк не важен.

## Пример

```
auth: passed, passed, failed, skipped  -> auth  3  66.7
legacy: skipped, skipped               -> legacy  0  (пусто)
```
