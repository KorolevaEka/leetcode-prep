# 1. Two Sum (Easy)

https://leetcode.com/problems/two-sum/

Дан массив `nums` и число `target`. Верни индексы двух элементов, сумма которых равна `target`.
Ровно одно решение, один элемент дважды брать нельзя, порядок индексов любой.

```
nums = [2,7,11,15], target = 9  ->  [0,1]
nums = [3,2,4],     target = 6  ->  [1,2]
nums = [3,3],       target = 6  ->  [0,1]
```

Ограничения: `2 <= len(nums) <= 10^4`. Получится быстрее, чем O(n²)?
