# Live Coding Trainings

Бесплатный тренажёр лайвкодинга на русском для QA-автоматизаторов и разработчиков.

**Сайт: https://korolevaeka.github.io/live-coding-trainings/**

## Возможности

- Четыре языка: Python, SQL, TypeScript, Java.
- Код запускается прямо в браузере, ничего ставить не нужно.
- Задачи разбиты по темам и уровням (easy / medium / hard), открываются по цепочке.
- Два вида задач: написать решение или написать тесты (проверяются на сломанных версиях кода).
- Вход через GitHub, прогресс сохраняется; гостям прогресс хранится в браузере.
- Все задачи проверяет CI: эталон проходит, ошибочные версии падают.

## Запуск локально

Нужен Docker.

```bash
docker compose up -d --build   # сайт на http://localhost:8000
./run test                     # тесты платформы
./run verify                   # проверка всех задач
```

## Как добавить задачу

Создайте папку `tasks/<язык>/<тема>/<NN>-<slug>/` и проверьте её командой
`./run verify tasks/<язык>/<тема>/<NN>-<slug>`. Формат задачи и правила написания условий — в [CLAUDE.md](CLAUDE.md).
Пуш в `main` публикует сайт, если тесты и проверка задач зелёные.
